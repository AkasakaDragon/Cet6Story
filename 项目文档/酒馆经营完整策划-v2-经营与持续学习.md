# 酒馆经营完整策划 v2：经营、伙伴成长与持续英语学习

更新日期：2026-10-12。适用项目：Cet6Story。

本文整合本次两轮玩法讨论及项目已有酒馆策划，作为后续开发、内容制作和试玩的统一设计基线。策划与实现状态分开记录；2026-10-13 已实现部分见《酒馆经营实现记录-20261013》。

用户明确方向：员工经验系统；同一知名度等级下每日普通来客人数固定；知名度升级带来更多顾客与产能压力；推进主线解锁主角团或NPC招募；背单词和听力与实际经营行为互动，不依赖词义与餐饮情境的对应；营业结束后仍可无限继续学习，并获得经验、好感等额外奖励。

具体人数、时间、经验、奖励强度、专长和事件均为初版设计建议，应通过试玩调整。主线招募人选、剧情节点与角色偏好需要对照既有剧情配置，本文不虚构已成立的人物关系。

## 1. 游戏定位与核心体验

玩家经营一家冒险者酒馆，安排菜单、设施、员工和接待策略；员工自动完成日常劳动，玩家通过词汇学习获得现场指导机会，通过真题听力培养员工的工作能力。酒馆成长推动玩家推进主线认识帮手，主线带来的伙伴与资源又改善经营。

营业有明确时段与客流，学习没有营业日限制。玩家打烊后可以继续研修，把额外学习转化为培养道具、伙伴礼物和下一次营业的准备。

核心循环：

> 准备经营 → 固定客流入店 → 学习与调度 → 接待结算 → 知名度与人员成长 → 新瓶颈 → 培养、设备、招募和主线 → 下一阶段经营。

持续学习循环：

> 营业中或打烊后学习 → 累积研修进度 → 自选道具 → 培养员工、增进关系或准备经营 → 在之后的营业和剧情中看见结果。

| 时间尺度 | 玩家期待 | 可见反馈 |
|---|---|---|
| 每组词汇练习 | 我能改善哪个问题？ | 批量备餐、优先收桌、安抚等候 |
| 每个听力题组 | 我正在培养谁？ | 经验、方向进度、已学技能协作 |
| 每个营业日 | 今天经营得怎样？ | 收入、瓶颈诊断、员工和菜谱成长 |
| 每几个营业日 | 酒馆又有什么变化？ | 知名度升级、熟客、新菜、设备 |
| 每个主线阶段 | 新伙伴能带来什么？ | 招募、新分工、角色故事、经营选择 |
| 持续研修 | 再学一组有什么收获？ | 可积累的经验道具、礼物、准备道具 |

设计底线：不用逐单答题解锁生产；不要求持续学习才能维持基础生意；不以随机答题掉落代替经营策略；不让学习抢走主线与实际工作的价值。

## 2. 既有基础与本版变化

现有基础依据项目文档《酒馆经营补齐与试玩-20261010》《酒馆透视与经营检查-20261010》整理，并非本次重新运行全部功能测试得出的结论。

| 系统 | 已有基础 | v2拟新增或调整 |
|---|---|---|
| 自动经营 | 厨师、服务员、四桌、制作送餐结账清理 | 三轮固定客流、瓶颈统计、更多员工 |
| 员工 | 四项能力、疲劳、五级成长、批量技能 | 培养方向、主线招募、后续十级与协作 |
| 菜谱设施 | 熟练度、库存、双锅、出餐台、预设布局 | 菜单策略、知名度配套升级、更多配方 |
| 词汇指导 | 共享词库与学习记录，每三题储备出品收益加成 | 可选择的经营指导及自动使用策略 |
| 真题听力 | 同屏题组、精听、员工经验、成绩区分 | 工作方向培养和题组边界协作反馈 |
| 持续学习 | 跨日保留部分学习状态、结束研修入口 | 明确的打烊研修状态、持续奖励道具 |
| 顾客关系 | 熟客、团体订餐基础 | 客群日程、熟客故事、伙伴礼物与关系节点 |

本版取代v1中“词汇学习仅提高下一单金币”“指导次数满后继续学习不再获得经营奖励”的单一反馈方式：词汇指导仍是有限的一次性经营作用，但有效学习始终可以继续积累研修奖励。道具兑换后的经验不属于每道菜直接答题加经验。

听力仍保留直接培养员工的作用。直接培养与通用研修奖励属于不同用途，数值需共同预算，不能重复发放同一份完成经验。

## 3. 玩家身份、员工岗位与场景

陆川代表玩家，负责安排、培养和决策，不计入自动劳动员工数。现有莉瑟负责厨房、艾莉娅负责大厅的基础分工保留；后续角色按剧情开放加入。

员工仅保留厨师、服务员两类岗位。厨师负责切配、烹饪、装盘及允许的补料补柴；服务员负责接待、送餐、结账、收桌及简单饮品。不新增独立调酒师、杂工或客房服务岗位。

固定斜上方经营视角，员工实际行走与工作。首阶段继续使用一楼大厅、吧台与厨房视窗；统一开放式经营底图属于后续美术工作，不是玩法成立的前置条件。

建筑关系固定：左侧壁炉、吧台、右侧上楼梯；吧台后通道连接厨房；厨房独立楼梯向下通往酒窖；前侧下方门为后门，通向后院卸货区；二层为围绕挑空大厅闭合的环形客房与走廊。

布局编辑暂停经营，只移动允许移动的设施。门、楼梯和主要结构不能因效率优化随意改写。已否决的tavern-structure.png不作为确认结构参考。

## 4. 营业日状态与时间规则

### 4.1 一个营业日的状态

| 状态 | 酒馆行为 | 学习行为 | 玩家操作 |
|---|---|---|---|
| 准备 | 无顾客入场 | 可以学习 | 菜单、采购、人员、目标、开店 |
| 第一轮 | 较舒缓接待 | 词汇与听力均可继续 | 学习、观察、有限指导 |
| 第二轮 | 集中客流 | 同上 | 判断主要积压，执行策略 |
| 第三轮 | 后续客流 | 同上 | 调整后检验效果 |
| 收尾 | 停止入场，处理已有顾客 | 完整保留当前学习 | 等待结算，处理正常收尾 |
| 打烊研修 | 员工待命或休息表现，不再产生营业收入 | 无次数限制 | 继续学习、领取道具、交谈 |
| 结算已阅 | 当日经营结果固定 | 可以继续研修 | 维持当前夜晚、主线、准备次日 |

“结算已阅”是标记，不是强制跳转画面。玩家可查看结算后返回同一个研修夜晚。离开前未读的结算可在经营记录中查看。

### 4.2 时间建议

- 正常速度下，普通营业日目标10～15分钟，不含玩家自由准备和打烊研修。
- 客流按三轮计划生成，初步采用25%／45%／30%的分布；按整数分配且总和严格等于当日固定来客数。
- 轮次间可有短暂间隙，但完整听力不需要恰好匹配某一轮时间。
- 经营暂停与加速不改变音频速度；精听慢速不改变经营速度。
- 学习默认不暂停营业；布局编辑等主动管理行为按既有暂停规则执行。
- 打烊继续学习不推进游戏日期，不产出工作经验、菜谱制作次数、金币或熟客接待成果。
- 次日只由玩家主动开始。允许沿用菜单与排班，跳过重复配置；录音与词汇进度不重置。

如果收尾遇到无法完成的缺料订单，可取消并按正常损失结算，不允许永久卡在收尾。

### 4.3 学习边界保护

当前题目或完整听力题组未结束时：结算进入角标，招聘、专长选择、重大剧情和特殊预约进入待处理列表。禁止自动提交、清空答案、截断录音或突然切换日期。

玩家主动结束研修时保留位置；未完成题组不发完整题组奖励，之后可继续。考试中断仍按考试规则记录，不伪装成未中断的独立成绩。

## 5. 开店准备与经营重点

开店前展示固定来客数、三轮人数、主要客群、已知预约、库存和预计产能。预测是提示而不是保证，尽量说明“厨房可能偏忙”等原因。

基础操作：选择最多三道料理和一种饮品；安排主要岗位与允许的协助任务；设置自动补购上限、缺料替代菜单、休息规则；选择一项经营重点。

| 经营重点 | 倾向 | 对应取舍 |
|---|---|---|
| 快速接待 | 优先减少等待和恢复空桌 | 复杂高价菜不是最佳选择 |
| 招牌推广 | 指定菜在实际制作时获得额外熟练度 | 集中点单增加厨房压力 |
| 熟客经营 | 对熟客接待投入更多交谈时间 | 服务员周转略慢 |

重点不能凭空增加完成订单或制作次数。开店后允许改变任务策略；更换已备菜的菜单需说明库存与订单影响，不取消正在制作的有效订单来刷熟练度。

## 6. 固定客流、知名度与升级压力

### 6.1 每日人数

| 等级 | 称号建议 | 每日固定普通来客 | 内容重点 |
|---|---|---:|---|
| 1 | 无名小馆 | 12 | 两名员工，基本流程与学习入口 |
| 2 | 街坊熟知 | 18 | 集中客流，第一类显著瓶颈 |
| 3 | 镇上热门 | 26 | 首次新增员工、成熟批量能力 |
| 4 | 商路名店 | 36 | 排班、客群、菜单和协作 |
| 5 | 冒险者据点 | 48 | 多人经营、特殊预约、更多设施 |
| 6 | 地区招牌 | 60 | 多策略成熟酒馆与可选挑战 |

人数是初版曲线。后期人数不能直接塞进首版四桌两员工容量，需配套人员、设施和允许扩展范围。

固定人数指来客计划，不是保证成交：到店、接待完成、正常离开、等待离开、预约改期分别统计。收尾不再追加新顾客。天气可影响构成、需求和到店节奏，不改变同等级普通来客总数。

普通团体预约占用当日固定名额，例如18人中有6名商队顾客。可选额外宴会以独立挑战处理，开始前明确额外人数，不混入普通经营。

### 6.2 知名度来源

知名度来自满意接待、招牌菜成果、熟客推荐和可选事件表现。学习完成、送礼、使用经验道具不直接增加知名度。

建议普通满意接待贡献主要进度，招牌和熟客提供阶段奖励；重复领取同一招牌成果不反复加分。升级条件在面板中提前显示。

升级发生于结算并在次日生效。前两级目标约每2～4个正常经营日获得明显进展；后续逐步放缓。最终阈值与员工曲线共同调试，不先锁死。

不因一次经营失误掉级；差表现减少当日增长和收入。首次进入新等级有明确客流预告、一次改进提示与可恢复损失，不额外给予永远需要学习才能维持的负面状态。

### 6.3 主线未到招募节点时的缓冲

升级后仍有三种改善途径：当前可用设施、现有员工培养、主线招募。面板明确指出招募开放的章节或任务。

可设接待上限，例如26位固定来客中今日接待20位，另外6位预先安排改期。改期无营业收入、无满意接待知名度，也不算差评；不累计成无限增长的次日额外队伍。之后日期依旧按固定总量重新排入计划。

接待上限帮助玩家维持酒馆，不应成为提高知名度的最佳方案。预约改期与因等待愤怒离店必须清楚区分。

## 7. 任务链、瓶颈与经营决策

顾客链：入场 → 入座 → 点单 → 制作／饮品 → 送餐 → 用餐 → 结账 → 收桌 → 离店。

员工任务必须唯一认领，原料领取时预留；没有足够原料、空设备或可达路径时不能假装工作。批量任务保持真实份数、成本、设备条件和订单归属。

| 瓶颈 | 画面与统计 | 解决方向 |
|---|---|---|
| 厨房 | 待制作订单、最长等待、炉灶占用 | 简化菜单、备餐指导、厨师、双锅 |
| 大厅 | 待送菜、未收桌、顾客等待 | 服务优先级、双盘、服务员 |
| 设备路线 | 等炉灶、交接拥堵、运输距离 | 出餐台、合法布局、设备升级 |
| 负荷分配 | 一人疲劳一人空闲、协助抢主业 | 调岗、协助开关、轮换 |

耐心分阶段下降：先少小费，再降低满意度，最后才离开。显示阶段与原因。安抚只能缓冲，不能永久保住未制作订单。

结算至少记录接待完成率、厨房与大厅峰值积压、制作／送餐／收桌等待、缺料次数、员工忙碌与疲劳情况。只展示两三条最有用诊断，详细数据放分页记录。

## 8. 词汇学习与现场经营指导

### 8.1 学习内容

复用现有四六级词库、复习和拼写记录，包含词义理解、搭配、语境选词、主动回忆等题型。优先安排到期复习，再结合新词和错词。三题作为初始短组建议，按学习量调整，不要求全对。

词汇内容不必对应餐饮。玩家学习任意适合其进度的词，获得的是选择经营动作的机会；不是学到某个词义才获得特定经营效果。

### 8.2 指导机会

完成有效短组并完成必要订正，获得一次指导机会；最多储备三次，跨日保存。达到上限后仍可继续学习并累积研修道具进度，不丢失学习价值。

| 指导 | 目标与效果 | 条件与限制 |
|---|---|---|
| 集中备餐 | 选一道菜，接下来两次合适制作优先合并或减少重复切配 | 真实耗料；并行烹饪仍需双锅；无对应订单则保留 |
| 大厅协调 | 接下来三项大厅任务优先送餐或收桌 | 不跳过在途动作，不导致其他任务永久饥饿 |
| 安抚等候 | 一桌或一批等候顾客恢复部分耐心 | 每位顾客每轮最多一次；不改变缺料事实 |
| 高峰轮换 | 同岗伙伴接替，让目标员工完成一次休息 | 需同岗伙伴且对方可接班；首阶段未满足时不提供 |

“集中备餐”早期可先实现同菜连续切配节约准备时间，已有双锅与批量技能后实现两份并行；指导不能绕过等级技能和设施条件。

指导主要改变工作顺序、准备损耗与临时协作，不直接永久增加能力、员工经验、菜谱次数或金币。新增收入来自实际多完成接待、品质或服务结果。

### 8.3 手动与自动策略

玩家可手动选择，也可开店前预设：厨房积压达到阈值则备餐、空桌不足则收桌、保留一次手动使用。自动判断只在合法动作中选择，不在无法生效时扣次数。

同一类状态不无限叠加。任务完成再消耗对应次数，目标消失前未生效的指导退回；已完成动作不退款。学习面板内用短提示显示选择、实际生效和待用次数。

兼容旧存档：原“下一单收益加成”按旧规则兑现一次，旧奖励余额保留但停止继续生成；新指导次数独立生成且上限明确，界面注明旧奖励与新指导，兑现完移除旧标记。

## 9. 真题听力与员工培养

### 9.1 内容与模式

使用四六级真题原录音及对应题目、选项、标准答案和完整题组。不自编订单听力替代真题，不为经营改写题目。缺失或对应关系不可靠的材料标为不可用，不补造真题。

保留四级／六级、年份、套卷、题组、培养对象和模式选择。考试练习与精听分开记录；原文、翻译、答案等辅助后的结果不能覆盖独立作答成绩。

考试按题组既有播放规则进行，中断如实记录；精听支持暂停、重听、逐句和设备支持的慢速。材料内部顺序、口播与录音时间轴须匹配。

### 9.2 长期培养

题组开始前选择一个已招募员工和培养方向。对象在题组中途锁定，之后切换只影响下一组。

| 岗位 | 方向 | 行为目标 |
|---|---|---|
| 厨师 | 批量处理 | 更合理地合并同菜订单与准备工作 |
| 厨师 | 稳定出品 | 高负荷时保持品质，适合复杂菜 |
| 服务员 | 大厅周转 | 安排送餐、返程收桌和交接 |
| 服务员 | 客情维护 | 安抚、熟客推荐、减少点单犹豫 |

完成题组获得基础经验；正确率提供有限额外经验；有效纠错提供复习进展。低分也培养，成绩不等于员工等级。

员工总经验由工作经验、听力经验、道具经验构成，分别展示贡献；培养方向进度用于专长节点，不再作为第二份同额经验重复累加。

现有每题组每日两次经营奖励的规则，调整为首次、有效复习和同内容重复分类：完整题组直接经验仍有防刷限制；持续有效学习的通用奖励不被营业日上限锁死。游戏日期重置不重置材料的重复判定。

### 9.3 当前经营反馈

开始录音前选择本轮目标：处理厨房积压、恢复空桌、保证招牌品质或平稳接待。员工按已有能力与优先级自动执行，不能通过目标选择免费获得未学会技能。

题组完成后展示培养成果和这段时间的经营摘要。提供一次已掌握技能的协作机会，例如成熟服务员带新人完成接下来几项大厅任务；按任务消耗、最多储备一次、不与其他协作无限叠加。

协作基础效果来自完成题组，不以高正确率作为救场门槛。打烊完成的协作保留到次日。尚未学会协作技能时只给培养成果和下一技能目标，不伪装成行为技能已解锁。

## 10. 员工等级、专长与招募

### 10.1 四项能力

手艺影响品质稳定；效率影响制作、行走和清理；服务影响接待、小费和熟客；体力影响连续工作与疲劳恢复。疲劳主要在超负荷下明显影响效率，合理休息能恢复，不添加频繁喂饭等维护负担。

员工仅通过实际完成任务取得工作经验，打烊休息动画无经验；同一任务不因拆分动作重复发经验。

### 10.2 等级节点

首阶段保留五级，后续主线阶段再开放至十级，不默认修改已满级员工的既有技能。

| 节点 | 内容 | 可观察行为 |
|---|---|---|
| 1 | 基础岗位 | 单份制作、单盘送餐 |
| 3 | 工作技能 | 双份切配／双盘送餐；保留设备条件 |
| 5 | 专长方向 | 返程收桌、精细接待、批量准备、稳定复杂菜 |
| 7 | 团队协作 | 带新人、改善交接、合理分担 |
| 10 | 专属能力与故事 | 特定料理或角色专长，体现既有身份 |

专长选择在题组间隙呈现，不打断录音；升级后当前动作先完成，新行为用于之后的任务。已获得的基础技能不因更换培养方向消失，方向切换需说明后续进度的去向。

道具可以加快经验与方向进度，但关键技能仍需要等级、实际工作经历和设施。满级时不消耗纯经验道具；方向满时不消耗带教道具，改为推荐其他对象。

### 10.3 招募渠道

普通NPC：主线解锁招聘渠道后出现，承担稳定劳动，有擅长岗位和温和优缺点。

主角团：达到既有剧情关系节点后开放驻店协助。剧情要求离队时提前告知、保存培养成果并提供经营缓冲，不无提示抽走核心员工。

每位员工需要岗位、初始能力、特长、培养方向、加入条件与小故事。新员工不全面胜过老员工；老员工保留熟练度、关系和专长优势。

首个新增员工建议能直接缓解首次明显瓶颈。具体角色名称和任务节点建立“主线—招募”配置表后确定，不把听力高分或大量送礼作为主线招募的唯一门槛。

排班以岗位和可选协助为主，不要求每道菜临时换人。高等级新增同时工作的名额，需要与场景路线、设备和工资共同验证；首阶段先做一个新增名额。

## 11. 持续研修与奖励进度

### 11.1 全时段统一计入

准备、营业、收尾、打烊均可学习，使用同一研修进度条。完成相同有效内容不因学习所处时段不同改变奖励，避免故意拖延到打烊刷收益。

到达一个奖励节点，自选员工培养、伙伴关系或经营准备三类道具。未领取奖励保留，不阻止继续学习。领取与使用不打断音频，不要求立即使用。

### 11.2 初步量化口径

以100点为一份标准奖励，目标相当于约8～12分钟正常有效学习量。该时间仅用于校准，不按在线时长发奖。

| 内容 | 初版进度建议 | 认定方式 |
|---|---:|---|
| 3个有效词汇学习单元 | 15点 | 新词、到期复习或真实错词巩固，含必要订正 |
| 完整听力题组 | 40～80点 | 按原材料长度与题数预设权重，不按用户反复播放时长增长 |
| 题组有效纠错 | 10～30点 | 首次订正与明确需要复习的内容；不自动按打开解析认定 |
| 多次立即重复同一已揭晓内容 | 0点新增完成奖励 | 仍保留学习功能和记录 |

这些权重不可直接作为最终平衡值。先用项目真实词组和真题组测耗时，使词汇、长对话和短篇听力的单位学习回报接近。

基础进度来自完成有效学习；独立作答表现可提供不超过基础20%的额外进度，纠错补回一部分，不能让低水平玩家长期缺少奖励。

无需限时回答。不能以慢速、辅助字幕或精听时长判定玩家不努力。辅助学习照常获取对应完成／复习进度，独立成绩另行保存。

### 11.3 有效复习与防刷

- 词汇奖励按学习单元识别，立即重做同一词不视为新词；后续到期复习正常计入。
- 新词学习、首次有效纠错、到期复习各有明确身份，不能把同一次答错拆成无限纠错奖励。
- 听力按材料与复习记录识别，重复播放不重复发完整题组完成奖励；有效精听订正和以后安排的复习有相应收益。
- 只播放不作答、只打开答案不完成订正，不产生完整奖励；不强迫用拼写才能领取全部奖励。
- 每个完成事件只发奖一次，保存后重载、跨日、切换员工或更换模式不能重新领取同一完成事件。
- 未练材料与到期复习持续有基础奖励，不设置“学到每日上限后全部无收益”。

“可无限继续学习”不等于同一材料每秒重复领取奖励。防刷限制针对内容重复，不能针对玩家主动延长学习时间。

### 11.4 阶段成果

较强奖励来自累计不同题组、按计划复习、有效错题订正等阶段目标。无连续登录要求、不因中断一天清空。

阶段奖励可包含较强手册、装饰、称号或角色交谈机会。经营核心能力不能全放在阶段奖励里，普通经营与基础学习应有完整成长道路。

## 12. 道具奖励、用途与经济边界

道具是额外学习成果，不可卖成大量金币，不作为采购必需品，不随机抽奖。名称是暂定表现，后续按世界观统一。

| 道具 | 用途 | 建议强度与限制 |
|---|---|---|
| 实务心得 | 指定员工直接获得少量经验 | 约相当于早期升一级所需经验的5%～10%；后期按固定经验档位，不永远按当前等级比例涨 |
| 带教手册 | 储备选定方向的培养进度 | 通过下一次相应实际工作逐步兑现；未完成部分跨日保留 |
| 茶点礼盒 | 与已结识角色分享，增加基础好感 | 符合偏好有小额额外收益；重要关系节点仍需剧情 |
| 心意小礼 | 阶段型关系奖励 | 温和提高关系或解锁一次交谈，不跨越主线关系条件 |
| 备餐计划 | 下一次营业减少一轮指定菜的准备负担 | 不生成原料、不跳过烹饪；同类当日仅装配一份 |
| 协作便笺 | 为下一次营业提供一次合法指导／协作 | 与已有技能兼容，不能新增永久技能；当日额外装配上限明确 |

标准奖励建议提供实务心得、茶点礼盒、备餐计划三选一；带教手册、心意小礼等放入阶段奖励或后续开放。首阶段不一次加入六种道具。

经营准备道具每个营业日最多装配一份；未使用部分按次数保存，不靠现实时间过期。自动提示“当前没有合适目标”，不误消耗。

背包堆叠与分页，不设置小容量导致继续学习奖励丢失。不催促清包，不设置强制领取时限。

经验道具不能直接提升知名度、原料或金币。伙伴礼物不能使尚未认识角色提前出现。经营道具只能改善有限任务，不能替代人员、设备与菜单策略。

## 13. 好感、伙伴相处与熟客的区别

伙伴好感用于已结识角色；熟客关系来自实际满意接待。两类关系分别保存，不用礼物直接刷顾客推荐知名度。

送礼前显示对象、基础收益、已知偏好及重复赠礼影响。同一角色同一游戏日建议第一次100%、第二次50%、第三次起20%的普通好感收益；这是可调数值，不禁止继续赠送。奖励礼物可跨日留存，玩家可以送给不同角色。

不设计厌恶礼物导致大幅扣关系的陷阱。偏好通过交谈自然发现，未知偏好也有基础收益。

关系节点可开放打烊交谈、人物看法、专属料理或装饰、搭档互动、温和协作能力和个人故事。节点需要剧情条件时显示“关系已足够，等待某段经历”，不继续吞掉礼物而无反馈。

重要剧情不因错过某天经营而永久丢失。学习得来的礼物创造相处动机，不能代替人物经历。

## 14. 菜谱、库存、设施与收支

菜谱至少包含售价、真实耗料、制作时间、设备需求、批量能力、品质与客群偏好。菜单少量上架，使选择有意义。

| 菜谱类型 | 价值 | 取舍 |
|---|---|---|
| 快手菜 | 快速出餐、低资源需求 | 单份利润较低 |
| 家常菜 | 稳定利润、适合批量 | 吸引特殊客群较弱 |
| 招牌菜 | 高收益和偏好满足 | 占用设备较久 |
| 分享餐 | 同桌团体的协调出餐 | 备餐与人数要求更高 |
| 限量特色菜 | 事件与高价值接待 | 原料有限、不能作为无限主力 |

实际制作才增长熟练度，延续初学—熟练—招牌。老菜保留成本、批量和熟客价值，不被新菜全面淘汰。

现有两种食材与基础菜先验证玩法，之后再扩配方；不因策划建议凭空替换既有料理。饮品仍由服务员兼顾，原料预留规则与厨房一致。

设施改变真实能力：双锅并行、出餐台改善交接、食材架减少搬运、餐桌增加容量但增加清理负担。预设布局先保留，自由移动与路径检查后续实现。

库存跨日保存；缺料暂停相关菜，自动补购受玩家金币和设定上限限制，不产生负库存或无限透支。应保证合理准备下能完整听完一组真题，无需十几秒补一次料。

结算区分营业收入、食材采购、其他成本和净收益；研修道具不计作营业收入。工资建议在首次正式招募阶段加入简化固定支出，先验证净收益可持续，不提前给两员工首阶段增加复杂费用。

破产缓冲保留基础菜、低成本经营和合理恢复机会；不要求先答题才能拿到维持营业的必需原料。冒险获得特殊材料、配方与伙伴，酒馆资金帮助采购与培养，具体兑换需与全游戏经济统一。

## 15. 客群、熟客与可选事件

| 客群 | 需求倾向 | 回报方向 |
|---|---|---|
| 镇民 | 实惠、及时、吃饱 | 稳定收入与熟客 |
| 冒险者 | 热食、饮品、充足份量 | 材料、委托与剧情线索 |
| 商人 | 服务、整队接待、环境 | 较高消费与采购机会 |
| 学者（后续） | 安静、品质、特别饮品 | 配方与知识线索 |

每日构成提前显示，同等级人数不变。熟客占用固定名额，不额外无限生成。每位熟客只保留少量可记住的偏好和特点，几次满意接待开放交谈、配方或委托。

事件建议每2～3个营业日出现一次；是否接受由玩家决定。事件不在听力播放时悄悄超时。

| 事件 | 挑战 | 结果 |
|---|---|---|
| 商队预约 | 集中备餐与同桌出餐 | 收入、推荐、采购机会 |
| 招牌试卖 | 菜谱品质与厨房占用 | 熟练度、知名度阶段成果 |
| 带新人 | 老员工协助与负荷 | 新人成长、伙伴小故事 |
| 雨夜避雨 | 固定名额内热食集中需求 | 熟客、交谈与经营反馈 |
| 熟客包桌 | 占用座位和利润取舍 | 关系与专属成果 |

可选挑战后期开放满座接待、主题宴会和料理评选。目标明确，失败可重试、不回收永久技能。奖励不能只堆更多强度，还应有装饰、故事和经营方向。

## 16. 同屏界面与音频规范

默认约六成场景、四成学习面板；提供观察酒馆与专注学习布局，后者仍保留实时小视窗。题干选项完整可读，长内容分页，切换保留输入、答案和录音位置。

打烊研修界面显示“今日已打烊”，明确无新顾客和营业收益；继续学习、奖励箱、伙伴相处、结算角标、准备次日均可访问。

奖励进度、经验条和技能反馈采用轻量动画。录音时不弹模态窗口、抢焦点、播放经营声音或强制打开礼包。背词输入不触发经营快捷键。

## 17. 成长节奏与平衡目标

| 阶段 | 目标体验 | 建议出现的成果 |
|---|---|---|
| 第1～2个营业日 | 理解自动劳动与学习反馈 | 一次有效指导、基础升级、第一份研修奖励 |
| 第3～5个营业日 | 发现并解决瓶颈 | 批量技能或设施改善、菜谱熟练、知名度进展 |
| 首次明显扩客 | 感到有新压力而有解决方向 | 招募提示、设备选择、接待上限 |
| 首次招募后 | 新伙伴确实让店运转更好 | 一轮更顺畅接待、新人培养、角色交谈 |
| 成熟阶段 | 形成不同经营风格 | 快速周转、品质招牌、熟客或团体方案 |

员工前期每1～2日接近一个成长成果，关键技能隔几个营业日出现。至少一次专长或设施让同样客流显著更顺畅，不只改变小数值。

学习指导解决局部问题，员工／设备解决结构问题。平衡时建议将一次指导收益控制在少量任务，不让连续做题抵消所有人数增长。

有效学习可持续获得小奖励；关键能力通过工作、设施和剧情条件控制，不靠把奖励条停掉控制成长。

纯经营玩家能维持并成长；学习玩家成长更快、培养更灵活、有更多关系与准备资源。任何经营挑战不得默认玩家必须高分答题。

## 18. 完整体验示例

### 18.1 营业中的词汇与听力

酒馆为街坊熟知，今日固定18人，三轮分别5、8、5人。莉瑟厨房、艾莉娅大厅。玩家预计第二轮较忙，选择两道快手菜与一道招牌菜，重点为快速接待。

第一轮学习到期词汇，储备两次指导，研修进度也增加。第二轮厨房积压，玩家一次指导集中备餐，另一次指导让大厅优先收桌。原料正常消耗，员工动作照常完成。

随后选择艾莉娅进行真题题组，培养大厅周转方向。录音期间员工继续工作，普通提示进入消息栏。题组结束展示经验与培养进度，玩家查看积压决定下一轮策略。

18人中完成16人，两人等待离开。结算指出厨房是主要瓶颈，建议双锅、菜单或新增厨师，不误导玩家继续增加服务员。

### 18.2 打烊后的持续研修

最后顾客离开时录音未结束，结算成为角标。玩家继续听完并订正，研修进度达到100，选择实务心得，奖励进入箱中。

玩家继续到期复习，不进入次日、不刷顾客和工作经验。又完成一段进度后选择茶点礼盒，留待次日送给已认识伙伴。新手册、礼物和录音位置都保存。

之后主动查看结算，沿用安排准备次日，给新人使用心得；赠礼带来小段交谈。昨晚额外学习变成今天可见的人物成长。

### 18.3 主线招募与产能升级

每日来客上涨至26人，当前岗位长期积压。玩家暂设接待上限20人，减少主动接受的复杂菜，并看到明确主线招募目标。

推进主线开放新人后，增加同岗分担；对新人进行听力培养和心得补充，但双锅和工作经历仍决定批量技能能否生效。新团队在同样26人下接待明显改善，玩家产生挑战下一等级的动力。

## 19. 存档、奖励与开发数据要求

本节供开发使用，内部字段不进入玩家流程。

| 数据类别 | 必须保存的内容 |
|---|---|
| 营业日 | 日期、状态、固定客流计划、已生成编号、接待上限、结算与已阅标记 |
| 经营 | 订单、任务认领、预留原料、设备占用、库存、收支、菜单与排班 |
| 知名度 | 累计进度、等级、待次日生效升级、已领阶段成果 |
| 员工 | 身份、招募状态、等级、各经验来源、能力、疲劳、技能与培养方向 |
| 指导 | 待用次数、排队目标、已生效次数、自动策略、旧加成余额 |
| 学习 | 词库与复习记录、题组、录音位置、答案、模式、中断和辅助标记 |
| 奖励 | 研修进度、完成事件记录、复习资格、待选奖励、已领取与库存 |
| 关系 | 伙伴好感、偏好已知状态、当日赠礼次数、剧情条件、熟客接待关系 |

建议以“一个有效学习完成事件”统一处理：保存学习结果 → 判定直接指导／听力培养 → 累积通用研修进度 → 生成奖励资格 → 保存领取状态。各奖励有独立归属但共用完成编号，避免切换模式重复结算。

发奖和记录完成状态必须作为一个不可重复执行的保存过程；中途退出不能导致已扣道具却没效果或已到账又能重领。恢复订单时不得重复扣料、重复生成固定顾客或重复结算。

奖励表、客流曲线、菜谱与技能条件尽量数据配置。新策划不要求一次性改写所有系统，先补状态与奖励闭环，再增加内容。

旧存档迁移保留金币、玩家存档、角色与学习进度，不重新开放未满足的主线。新字段采用安全默认值，不追溯补发所有历史学习奖励；当前未完成学习继续，新有效事件起计入。

## 20. 分阶段开发范围

### 阶段A：经营与持续学习闭环

- 固定人数、三轮客流、知名度前两三级、次日生效。
- 厨房／大厅瓶颈反馈与基本结算建议。
- 三种现场指导及自动使用策略，高峰轮换暂不开放。
- 打烊研修状态、结算角标、持续学习与跨日恢复。
- 统一研修进度，经验心得、普通礼物、备餐计划三选一。
- 保留真题完整性、音频避让、独立与辅助成绩。

目标：三至五个营业日可体验成长，同时一次连续研修超过一小时仍可学习、保存和获得有效奖励。

### 阶段B：人物与招募

- 具体主线招募映射和一个新增员工名额。
- 厨师／服务员各两个培养方向，行为明确。
- 新人成长、同岗轮换、伙伴赠礼和一个关系交谈。
- 熟客与一项占固定名额的预约事件。
- 验证招募改变瓶颈、礼物不越过剧情。

### 阶段C：成熟经营

- 后续等级、十级员工、更多菜单与专属技能。
- 搭档协作、团体策略、更多熟客与可选挑战。
- 数据支持的高级客流与同时工作容量。
- 酒窖陈酿、二层简化住宿；入住退房以系统处理，仍不增加客房服务岗位。
- 完整套卷、错题原因与复习推荐；不删已有题组学习能力。

自由建造整栋建筑、大量随机性格、现实时间等待、强制日常和离线收益不属于当前必要范围。

## 21. 验收与试玩指标

### 21.1 功能验收

- 同等级普通来客每天严格固定，三轮总数相符；熟客和预约不额外叠加。
- 来客计划和已生成编号恢复后不重复；接待上限不变成次日无限积压。
- 知名度来自实际成果，升级次日生效；未到招募节点仍能通过现有途径维持经营。
- 员工技能和指导改变可观察工作，原料、设备、路径条件真实存在。
- 指导上限三次、跨日保留；无法生效不消耗，不无限叠加。
- 学习期间营业继续，不要求强制抢点；特殊事件等待题组边界。
- 真题音频、题组与答案一致；考试、中断和辅助成绩不互相覆盖。
- 营业结束不截断听力、不清空学习；研修不自动推进日期。
- 打烊无营业收入或工作经验，额外学习正常产生研修成果。
- 学习超过奖励节点后进度继续累积；未领取不丢失；保存恢复不重发。
- 到期复习有正常奖励，立即刷相同答案无重复完成收益。
- 道具使用、满级、未解锁角色、无合法任务时反馈明确，不误消耗。
- 好感道具不能跳过主线；熟客关系与伙伴好感分开。
- 无默认滚动条、黑角、截断选项；键盘焦点与音频速度不串扰。

### 21.2 体验验收

建议在同客流下比较三种方案：普通配置、合理菜单／排班、加入培养／指导。优化方案应明显改善等待，连续学习不能掩盖所有结构问题。

至少观察：

| 指标 | 希望验证的问题 |
|---|---|
| 各等级接待完成率 | 升级是否带来可恢复的新压力 |
| 厨房／大厅等待与占用 | 是否存在不同瓶颈和多种解决方案 |
| 指导选择分布 | 是否有一个动作永远最优 |
| 菜单使用分布 | 是否全上最贵菜或最快菜成为唯一解 |
| 每分钟有效学习回报 | 词汇与听力是否大致公平，辅助学习是否受不合理惩罚 |
| 员工工作／听力／道具经验占比 | 道具是否取代实际经营，工作是否仍有价值 |
| 打烊继续学习率 | 玩家是否愿意留下，而非只被奖励迫使继续 |
| 新员工加入前后改善 | 招募是否带来真实行为和产能变化 |
| 礼物使用与关系节点 | 是否有相处期待，是否产生刷礼物跳剧情 |

不以玩家学习时间越长作为唯一成功指标。玩家能自由结束，下一次愿意回来，并理解学习与经营的联系，才说明闭环成立。
