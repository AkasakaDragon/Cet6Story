# 主线地点怪物设计草案

以下怪物为2026-10-06新增设计提案，尚未写入主线剧情或替换游戏资源。地点取自主线策划；后续章节本身仍为暂定方案。先预览**荆棘孢子兽**，确认画风后逐只制作。

| 剧情地点 | 怪物提案 | 轮廓与材质 | 战斗特色提案 |
| --- | --- | --- | --- |
| **驿站**及附近林地 | **荆棘孢子兽**（现有怪物重设计） | 低伏四足兽，树皮甲、骨色荆棘、少量紫菌簇；紫光局限于眼睛与菌褶 | 保留撕咬、扎根加盾、孢子喷吐的现有行为；视觉对应前爪、根足、菌褶 |
| **边境小镇**外围供货路 | **缚索盗粮兽** | 瘦长獾形兽，断裂麻绳与偷来的布袋，锈色小角 | 突袭后排、拖拽换位；守护和不退可应对。镇内仍为生活场景，不随处安排野怪 |
| **旧矿道**／**第一层入口** | **矿脉钳兽** | 六足甲壳兽，石灰岩背甲、铁矿红纹、大钳 | 周期加盾与重击，破盾创造输出窗口 |
| **沉没工坊** | **漏液炼金偶** | 歪斜黄铜机械偶、玻璃药罐、绿铜锈、破损机械臂 | 护盾和自我修复；禁言可设计为阻止炼金修复，而非禁止所有机械动作 |
| **王国旧仓** | **封蜡吞箱怪** | 货箱伪装，红色封蜡为眼、铁箍为颚，货签碎片为尾 | 伪装蓄力与吞物加盾；调查揭露伪装后开战 |
| **古族庭院** | **断契藤鹿** | 石白鹿身、苔藓裂纹、藤蔓分叉角，少量青金契文 | 共鸣护盾与符印转移，强调古族旧契约线索 |
| **骑士墓廊** | **空誓守铠** | 无人盔甲，断剑与破盾，胸甲内有冷色残火 | 守护、反击、决意；与艾莉娅守护誓约形成镜像 |
| **裂隙前线** | **裂隙镰翼兽** | 瘦高双足、镰形前肢、撕裂翼膜、暗紫裂纹 | 前后排压迫与灼烧；适合守城段多目标战斗 |
| **最深层封印王座** | **锁印吞契者**（王座守卫） | 被封印石环约束的巨大兽体，破裂锁链、黑石鳞片 | 分阶段护盾与符印干扰；魔王本体单独按最终剧情设计 |

## 首只预览：荆棘孢子兽

保留剧情既有名字与受裂隙侵染的身份，削弱旧形象中过大的霓虹蘑菇，强化真实站姿和荆棘森林兽的可读轮廓。头朝左，适配敌方站位；完整四足、尾巴、背刺均留出裁切余量。

美术使用实际风格参考原图，并对齐男女主战斗立绘的方形像素颗粒、阶梯边缘和局部色阶。透明底单体素材，不混入角色、场景、文字或界面。后续动画采用独立动作帧，不用整体左右摇摆代替动作。

草案中的新怪物技能均为设计建议；当前代码尚未实现这些新敌人行为。

## 蘑菇林地生态图鉴（新增外形预览）

本区域为驿站附近受孢子侵染林地的美术与遭遇方案，不自行确定新的主线地名。用户已认可职业分工，先制作九种怪物的外形总览，尚未接入战斗。

| 怪物 | 职业 | 外形识别点 |
| --- | --- | --- |
| **荆棘孢子兽** | 高血量战士 | 树皮甲四足兽、骨色荆棘、紫色菌簇 |
| **伞冠角鹿** | 均衡战士 | 修长鹿身、鹿角托菌伞、苔藓护颈 |
| **灯笼菌蛾** | 单体法师／飞行 | 菌褶纹翅膀、垂挂发光菌囊、藤状触须 |
| **合唱伞灵** | 群体法师 | 三个高低错落的菌盖，菌褶发光，共用根须身体 |
| **影褶螳螂** | 刺客 | 折伞镰足、枯叶伪装、黑色薄菌膜 |
| **针孢树蜥** | 单体长弓手 | 弓形长尾、拉紧的菌丝、硬化菌针箭 |
| **鼓腹炮菇蟾** | 群体炮手 | 风箱腹部、背部长中空炮筒菇；必须准备一回合才开炮 |
| **涡伞水母** | 水生群体法师 | 青蓝透明菌伞、菌丝触须、水流旋涡 |
| **苔壳搬运蟹** | 防御战士／两栖 | 树桩壳、层叠小蘑菇、不对称巨钳与河石 |

统一参考战斗角色的像素密度与原图画风；飞行、地面、水生形态均保留完整轮廓与裁切余量。首轮总览用于确认外形，实际游戏素材随后独立生成透明底立绘与动作帧。

## 当前制作范围：蘑菇林地五种（2026-10-07）

此节覆盖上面的九种历史方案：只保留荆棘孢子兽（战士）、苔壳搬运蟹（坦克）、灯笼菌蛾（法师）、合唱伞灵（增益吟游诗人）、鼓腹炮菇蟾（炮手）。本版远程物理采用炮手，不另做弓手。角鹿、螳螂、树蜥、水母暂不制作、不编入遭遇；旧图保留作历史参考。合唱伞灵改为单次选择强力、格挡或净化的辅助，不再群体施毒。具体技能、施法位置、速度及遭遇搭配以《战斗技能最终设计-v4.md》现行五种条目为准。尚未接入游戏。
