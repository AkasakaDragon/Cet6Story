# 第一章：首次营业顺序调整

第一、二节保持现有剧情。第三节“午后：开门前的准备”负责备货、核对破损鸡蛋、试菜、出菜动线和收集矿道线索；尚未接单，没有营业收入。第四节莉瑟来访，招待的是试菜的汤，三人决定先调查再开门。第五节矿道剧情保持不变。

第六节“夜晚：第一次营业”：三人返回 → 碎片修复第一道裂痕 → 重新热汤、点灯、翻转营业牌 → 送货人与守卫首次进店用餐 → 晶石能量稳定，其他裂痕仍在 → 收入二十四枚减成本十八枚，盈余六枚 → 莉瑟身份揭示、艾莉娅留下、打烊。

第三节两张 CG 改为人物主导的食材核对与试菜镜头，采用增强的像素簇和阶梯边缘，背景仅保留木桌与窗光等锚点；试菜图不展示水晶。先前生成的两张食材/空厅环境草稿不用于 CG。第六节收尾 CG 使用账本、少量铜币和仍有裂痕的晶石特写。

改写台词已更新英文配音和时间轴；未改写台词保留原音频片段，包括莉瑟的既有配音。第三、六节题目同步对应新剧情，四道题及章节 ID 保持不变。
