# JSONL 释义导入

以用户提供的四级、六级 JSONL 的 trans.tranCn 字段为主要释义来源，只更新当前词表已有单词；同词跨记录按词性归并并去重。不把同近义解释、记忆口诀、试题解析混入释义。已核实的 dictionary-corrections 修正优先。

四级 4,371 词中匹配 4,001；六级 2,610 词中匹配 2,422。无匹配有效释义的保留原内容。共同查词覆盖 5,147 个不同词（含少量无 JSONL 匹配的已核实修正）。没有扩充词表，不改例句、题型和玩家学习进度。

word-meanings.json 在词典加载时覆盖旧释义，随后加载人工修正，保留原音标。旧题目结算、中文答题提示及收藏显示读取新释义，不批量改写玩家存档，也不重排正在答题的选择项或修改其答案索引。

导入程序 tools/import-word-meanings.py；详细匹配缺失名单和来源哈希见同名 JSON 报告。ImportedMeaningChecks 全量验证运行时覆盖一致；WordExampleChecks 验证旧题释义、例句与进度；DictionaryFormChecks 验证原形补充关系和人工修正优先。
