# 第一卷第一章配音来源与发行许可

本章四节均为原创台词，使用 Edge/Bing 在线语音接口预生成音频；运行游戏无需联网。用户已授权将本节台词发送到该服务生成配音。

声线：陈星遥 en-US-MichelleNeural；陆川 en-US-BrianNeural；旁白 en-US-ChristopherNeural；系统 en-US-GuyNeural。未使用真人声音克隆。

当前版本用于本地开发试听。尚未核实 Edge/Bing 接口输出的游戏发行或商业使用授权，不能因接口免费、可以下载，或客户端库开源而认定音频可商用。

正式发行前，应通过许可明确的语音服务重新生成。微软 Azure 产品条款明确规定，付费 TTS 服务客户可将预置神经网络声音的输出用于商业用途；此条款不能直接套用到 Edge/Bing 接口生成的音频。

核查日期：2026-10-02。
