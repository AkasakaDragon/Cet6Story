# 双语例句导入核对

数据由用户提供的 KyleBing/english-vocabulary 正序完整版四级、六级 JSONL 文件导入。原文件保持不变；来源仓库：https://github.com/KyleBing/english-vocabulary 。原始数据经该仓库从 kajweb/dict、KyleBing/dict 整理，不能把仓库代码许可直接等同于全部上游词典内容的授权。

## 导入结果

- 原始四级 7,508 条，六级 5,651 条，包含多套词书重复词条。
- 独立资料库 `assets/word-examples.json` 收录 5,680 个词、8,782 条双语例句，每词最多两条。
- 游戏四级训练词表仍为 4,371 词，其中 3,553 词有匹配例句；六级仍为 2,610 词，其中 2,156 词有匹配例句。两个训练词表存在重叠，匹配数不能作为去重词数相加。
- 完整来源 SHA-256、覆盖数量和未匹配单词见同目录 JSON 核对报告。

只提取英文例句和中文翻译；未导入释义、音标、词性、搭配、近义词、同根词、真题片段、考频或题目。已有释义、训练词表、剧情例句与玩家记录均不被替换。补充资料中训练范围外的词可供点击查词使用，不会加入训练池。

## 筛选与显示

清除 HTML 标签、合并空白，排除缺少中英文一侧、含省略片段、超长文本以及无句末标点的短语碎片。同一词的相同英文例句去重，即使中文译文略有不同，也只保留一份。优先选择包含词条本身、长度适中的例句；允许例句使用变形词。

该筛选是结构和文本检查，不代表对全部例句的语法、翻译、词义匹配都做了人工审核。没有符合条件的例句时不编造补充，也不自动把复数、派生词合并到词根，以免匹配错误词义。

剧情、听力和生词本查词统一使用深绿金边单词弹窗，先显示原有释义和当前语境，再显示补充双语例句。长内容分页，不使用默认滚动条；生词本列表点击英文词名即可打开。

答题解析仅在原有例句为空或为占位练习句时显示补充双语例句，不修改题目对象、不启用新的填空题型、不重置正在进行的训练。已有剧情例句及其译文优先保留。

## 验证

`tools/WordExampleChecks.cs` 检查双语配对与去重、大小写查词、训练数量、原有例句优先、解析显示、查词不改变收藏数量和金币、无默认滚动条，以及缩放分页后的例句完整可达性。游戏编译和该检查均通过。

重新生成：运行 `tools/import-word-examples.py`，传入原始四级、六级文件路径。该脚本仅写补充例句库与核对报告，不写训练词表或存档。
