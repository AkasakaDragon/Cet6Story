# 词域远征 · 分叉地图背单词

主菜单点击“背单词”。地图采用森林水域与夕阳遗迹的精美像素风，只显示节点、连接路线与返回按钮，不显示编号、头像、生命或攻击属性。战斗进入森林遗迹、地下石殿、熔火峡谷，沿用白发黑衣陈星遥立绘。

## 地图与节点

每局八层，除起点和最终首领外每层三个节点。只有当前路线相连的下一层节点可点击；可进入节点以明亮图标与左侧小箭头标示，所有图标去掉底框并放大。悬停查看用途，左右方向键与 Enter 也可选路。路线随开局生成并保存，返回大厅或重启不会重抽。

| 节点 | 功能 |
| --- | --- |
| 小怪 | 战胜后获得 8–12 金币 |
| 精英 | 战胜后获得 20–30 金币，并三选一赋能 |
| 火堆 | 恢复生命上限的 30%，或本局攻击 +3；只能选一次 |
| 问号 | 五种随机情节：献祭石碑、旅行者药箱、流浪商人、解救木灵、遗忘词匣 |
| 宝箱 | 普通宝箱 15 金币；稀有宝箱 20 金币并三选一赋能 |
| 商店 | 使用永久金币购买本局恢复、提示和赋能 |
| BOSS | 先出现遭遇页，再挑战古界守门者；胜利获得 40–50 金币 |

第一层固定小怪，第五层固定宝箱，第十一层固定火堆，最后固定 BOSS。第四层起才出现精英，不安排连续精英层；每条路线都有宝箱及最终战前的火堆。

事件中的战斗奖励基础 12 金币。献祭需 12 生命换随机赋能，也可安全领取 8 金币；药箱支付 15 金币恢复 35 生命，也可免费恢复 10；流浪商人以 45 金币出售攻击 +4 的符石。解救事件和词匣可以接受战斗，或选择安全的金币/提示。

## 答题与战斗

初始生命 100、攻击 15、提示 1；已购买的成长升级继续生效。

题型为看英文选中文、根据词义选英文、语境填空、拼写。基础训练不出拼写。选择题按 1–4，拼写按 Enter，反馈页按 Enter 继续。

战斗已升级为双星卡牌系统：男主在女主身后出牌支援，女主答对发动攻击。开场抽 4 张牌，之后每回合抽 2 张，每回合 3 能量。怪物按预告技能循环行动，替代旧版每三连击反击规则。答错断连击并按怪物本回合行动结算，错词自动进入生词本。详见《双星卡牌战斗-玩法说明》。普通敌人生命 110–130，精英 198–210，首领 340。基础攻击下，小怪约需 5–6 次正确作答，精英约 8–9 次，首领约 15 次；攻击与赋能会改变实际题量。已有十二层远征保留原路线及战斗规则，新开局采用八层地图。敌人伤害随深入增加，护甲减伤。

战斗包含前冲、金色攻击轨迹、斩击、像素粒子、受击闪色、轻微震动与伤害数字。特效每次提交播放一次，停在反馈页不会不断循环攻击。场景缩放使用像素采样并缓存背景。

单词旁依次为喇叭、收藏星星、提示灯泡。看英文选词义和拼写题自动发音；根据词义选词、语境填空不自动发音。反馈标题右侧也有喇叭与收藏按钮。

提示显示单词与词义，本题伤害降低，无每日金币及词汇准备进度。本场使用过任何提示，战利品减半；提示不会影响已有收藏。

## 金币与赋能

只保留一份永久金币余额，地图商店、成长商店、主线系统商店共同使用。旧版未完成远征的剩余补给币进入新模块时自动转换一次。

每词每天首次无提示答对 +3 金币。小怪、精英、宝箱、事件和 BOSS 的金币另行计算。失败、主动结束、关闭游戏均保留已经获得的金币。首领奖励不会重复结算，也不会再追加旧版的 20 金币奖励。

| 赋能 | 本局效果 |
| --- | --- |
| 锋刃符石 | 攻击 +4 |
| 守护刻印 | 护甲 +2 |
| 生命琥珀 | 上限 +20，恢复 20 生命 |
| 回春枝 | 每场胜利恢复 8 生命 |
| 智慧烛火 | 提示 +1 |
| 连击纹章 | 每层连击额外增加 1 伤害 |
| 寻金罗盘 | 每场战斗多获得 5 金币，再应用提示减半 |
| 庇护羽毛 | 每场第一次答错的伤害减半 |

战后赋能只由精英、稀有宝箱或部分事件提供，小怪不再每次都送赋能。赋能在本局结束后消失，成长商店的永久升级保留。

地图商店每次到店限购一次：35 金币恢复 30 生命；20 金币增加一次提示；80 金币购买攻击 +4 或护甲 +2。满生命不能买恢复药剂。成长商店仍为生命升级 60、攻击升级 80、提示升级 50 金币，下局生效。

主线道具售价保持：临时身份屏蔽器 120、信号干扰器 120、档案扫描器 180、协议修复芯片 240 金币。地图赋能不能当作主线道具使用。

## 词库与本节准备

内置 143 个学习词及原创例句，不是完整四六级真题词库。基础、进阶、六级挑战分别选择不同难度。“我的生词本”至少需四词和四种不同释义；没有原创配套例句的收藏词不会出填空。

大厅的“本节词库”使用当前剧情小节的 24 个核心词。优先练未准备词，每词在两种不同题型中无提示答对才计为已准备。进度与原有“本节词汇准备”共享，跨局保存；首次完成整节准备另奖 60 金币。完成准备后可离开远征去主线商店，也可继续挑战首领。通过地图不等于自动完成词汇准备，词汇准备完成也不要求击败首领。

原有独立准备战斗保留，不占用普通远征存档，也换用了新森林背景、怪物与攻击特效。

## 存档与验证

地图、选路、生命、题目、赋能、宝箱领取、事件类型及商店购买记录都写入原有 save.json。退出后继续同一局，战败也保留金币、收藏、学习统计和准备进度。原有剧情、星级和已使用道具保持兼容。

本版验证覆盖 80 个种子的完整远征、1802 次作答、路线可达、精英间隔、宝箱/火堆保证、序列化恢复、重复奖励、提示减半、五种事件、商店消费、战败与旧局迁移。四节词汇准备共 192 道题的回归通过，另检查实际地图点击、战斗、精英、宝箱、事件、BOSS 及 800×500 小窗口。

本局已获得的赋能以透明底像素图标显示在地图与战斗界面右上角。同种赋能合并，重复获得显示叠加数量；鼠标悬停查看名称与效果，窗口缩小时自动换行。
