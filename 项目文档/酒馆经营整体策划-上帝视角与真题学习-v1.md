# 酒馆经营整体策划：上帝视角与真题学习 v1

更新日期：2026-10-09。

本文整合本次讨论中的酒馆经营、员工成长、布局、菜谱、英语指导与四六级真题听力方案，作为后续实现和评审的设计基线。上帝视角经营、持续成长体验、营业与学习同时进行及听力必须使用四六级真题属于用户明确方向；具体属性、奖励、数量和节奏是当前建议，需通过试玩调整。本文不表示相关功能已经实现，也不替代现有主线、战斗与世界观策划。

## 1. 核心定位

玩家经营一家冒险者酒馆，从固定的斜上方视角观察员工自动工作，通过安排岗位、调整布局、培养员工和经营菜单，让小酒馆逐渐成长为热闹的旅店。

主要体验：安排好酒馆 → 员工自动营业，玩家边看边学 → 英语指导提高单次收益，听力推动员工成长 → 现场看见效率改善 → 调整布局和菜单，迎接新需求。

经营与学习共享同一个画面和同一段游戏时间。酒馆是玩家学习时持续变化的陪伴和成长反馈：玩家做题时厨师继续做菜，服务员继续接待，金币、工作经验和熟客进度继续积累。英语指导与真题听力是营业中的主要玩家活动，不放到打烊后才开始，也不默认打开学习就暂停营业。

借鉴开罗式经营的成长节奏和可观察劳动过程，保留本游戏既有角色、剧情、像素绘画和英语学习特色。提升必须同时表现为数值、动作和场景变化，例如双盘送餐、等待减少、熟客回访、新区域开放。

## 2. 视角、空间与画面

- 固定 2.5D 斜上方视角，隐藏屋顶；玩家点击员工和设施操作，不直接控制角色移动。
- 首版展示一楼大厅、吧台和厨房，尽量能在同一经营视图观察接待与制作。
- 后续通过楼层或区域切换查看二层客房与酒窖；未显示区域仍参与模拟。
- 保持大厅左侧壁炉、吧台、右侧上楼梯的空间关系；吧台后方通道连接厨房，厨房独立楼梯通往地下酒窖。
- 前侧下方门为后门，外接后院与卸货区；二层为围绕挑空大厅的完整环形客房与走廊。
- 已否决的 tavern-structure.png 不能作为确认结构参考。

经营视图需要清楚展示员工工作和行走，因此使用可读的空间布局；剧情 CG 继续遵循人物主导的分镜构图。新经营素材按 assets/art-style/STYLE.md 和相关原始参考图生成，保持细腻像素绘画，不擅自变成粗马赛克或光滑动漫。

当前主界面继续使用静态 town-main.png。经营场景中的员工动作不意味着重新启用主页动画。

## 3. 一个营业日的循环

### 开店前

查看预计客群和预约，安排主要岗位及协助任务，选择菜单，采购食材，检查设施与库存，选择当天经营目标。

### 营业中

客人进门 → 找座位 → 点单 → 厨房制作或吧台出饮品 → 送餐 → 用餐交谈 → 结账 → 收拾桌子。

员工自动完成流程，玩家打开同屏学习面板进行英语指导或真题听力。场景保持可见和运转，玩家可在题目间隙查看积压、调整优先级、领取成长并决定是否接受特殊订单。员工不因玩家正在指导而停止工作，也不要求男主亲自做菜或端盘。

提供手动暂停与加速，默认学习时保持正常经营速度，听力播放速度与经营速度互不影响。经营安排以开店前和练习间隙为主，不要求玩家在听音频时抢点事件。普通经营提醒进入消息栏，剧情和重大经营选择等当前题目或完整听力题组结束后再呈现。

### 打烊后

结算收入、成本、满意度和目标成果，整理已在营业中获得的经验及成长；随后调整布局、菜单与采购。不把打烊作为英语指导、背单词或真题听力的开启条件。

若营业时段结束时正在学习，停止新客入场，员工继续处理已有订单；结算以角标提示等待。当前英语题目或完整听力题组完成后，由玩家查看结算并开始下一营业日，不弹窗截断音频、不自动提交答案、不清空学习进度。长时间精听可跨越多个营业日，题组边界提供简短结算与“沿用安排继续营业”，不要求重新配置所有项目。

基础循环按营业日推进，不依赖现实时间等待。是否加入离线收益留待后续决定。

## 4. 员工岗位与自动工作

首版只有厨师和服务员两名员工，不设置杂工，也不把男主计入自动工作的员工队伍。男主由玩家代表，负责经营安排、人员培养、英语指导和事件决策。饮品由服务员兼顾出餐，后续也不增加调酒师或客房服务岗位。员工岗位保持厨师和服务员两类。具体人选沿用剧情身份，不凭空改写既有角色。

采用“主要岗位＋允许协助任务”：

| 岗位 | 优先工作 | 可选协助 |
|---|---|---|
| 厨师 | 切配、烹饪、装盘 | 补充食材、清洗厨具、补柴 |
| 服务员 | 点单、送餐、结账 | 收桌、简单饮品出餐 |

同一任务只能由一名员工认领；协助任务不能长期压过主要岗位。任务无法进行时显示具体原因，例如缺料、设备占用或道路不通。员工需要休息，避免反复手动救场成为日常负担。

## 5. 员工能力与成长

| 能力 | 作用 | 可观察结果 |
|---|---|---|
| 手艺 | 菜品、酒水品质与稳定性 | 优质出品增加 |
| 效率 | 制作、搬运和清理速度 | 等待与积压减少 |
| 服务 | 接待、推荐、安抚与熟客关系 | 满意度、小费与回访改善 |
| 体力 | 连续工作与疲劳恢复 | 忙碌时保持效率 |

实际工作获得经验，基础升级小幅提高能力；关键等级解锁改变工作方式的技能。悟性作为部分员工的特长，不增加为所有人必须培养的第五项属性。

首版员工等级上限暂定五级，三级和五级各有一次明显技能成长。技能示例：双份切配、双盘送餐、主动补柴、空闲收桌、拿手料理。批量处理技能需有对应动画和任务行为，不能只写在说明中。

每位员工先有一个特长，例如细心、健谈、擅长烘烤；优缺点应温和且能通过分工发挥价值。后续再加入专属技能、员工小故事与固定搭档效果。搭档以长期协作形成，提供交接效率或熟客收益，避免成为必须频繁轮换的额外操作。

## 6. 菜谱、设施与布局

菜谱成长：初学 → 熟练 → 招牌。通过实际制作积累熟练度，逐步改善品质、耗时和吸引力。不同菜对应不同客群及成本，老菜可以凭熟练度与偏好继续有价值，不被新菜全面替代。

设施升级应带来实际能力，例如双锅炉灶增加同时制作数量，出餐台改善交接，酒窖开放陈酿，客房带来住宿需求。

布局以可移动设施和工作距离产生取舍：食材架靠近切配台减少搬运，出餐台靠近出口缩短送餐路线，增加桌子提高容量却增加清理与通行压力。

编辑布局时暂停经营，提供占地、可放置位置和通路反馈；禁止堵死必要入口。门、楼梯及关键建筑关系保留。首版不做任意拆墙或无限扩建。

## 7. 客群、熟客与事件

| 客群 | 主要需求 | 回报方向 |
|---|---|---|
| 镇民 | 实惠、及时、吃得饱 | 稳定收入和熟客 |
| 商人 | 服务与环境 | 较高消费、采购机会 |
| 冒险者 | 热食、酒水与情报 | 材料、委托和剧情 |
| 学者（后续） | 安静位置与特别饮品 | 配方与知识 |

首版先做镇民和冒险者。满意接待积累熟客关系，熟客回访、偏好和奖励需要可见反馈。

特殊事件包括商队团体订餐、新菜试卖、重要客人到访及材料交换。玩家判断当前产能后决定是否接受；提前告知需求与回报，不靠隐藏规则制造失败。事件中的一般经营对白可以使用英语，但不得把自编对白当作真题听力练习。

## 8. 持续成长与经济

| 节奏 | 进展 |
|---|---|
| 每次工作 | 收入、经验、菜谱熟练度、优质出品 |
| 每个营业日 | 员工升级、每日目标、熟客进展、设施改善 |
| 每几个营业日 | 新菜、新员工、新客群、酒馆升星、新区域 |

同时展示少量接近完成的目标，例如服务员即将升级、设施资金即将够用、招牌菜还差几次制作。目标应自然来自经营，不要求大量重复点击。

金币用于采购和设施；员工经验来自工作；菜谱熟练度来自制作；真题听力直接提供额外员工经验，通过升级提高能力并解锁技能；英语指导只提供一次性出品或服务加成，不额外设置培训货币。首版控制资源种类，不为每个系统增加独立货币。

酒馆升星综合满意接待、招牌菜和熟客等表现，开放新内容。收入结算区分营业收入、食材等成本和净收益；奖励不能掩盖实际亏损。工资、设备损耗等复杂成本后续再评估。

问题以温和、可恢复为原则：等待降低评价，疲劳降低效率，缺料暂停对应生产。通过画面和简短提示说明原因；避免一次小失误造成无法恢复的连锁崩盘。资金不足时保留基础经营与恢复机会。

具体价格、经验曲线和培训奖励暂不定死，试玩时检查是否形成唯一最优菜单、是否能无限刷奖励，以及玩家是否确实感到持续进步。

## 9. 英语指导

营业时，员工持续自动工作。玩家在同屏面板选择“英语指导”，完成一组简短英语练习，获得一次性出品或服务质量加成，提高对应订单的金币收益；不直接增加员工经验、永久能力或菜谱熟练度；每三题形成一个阶段反馈，玩家可以继续下一组，不强制退出学习面板；根据节奏调整。英语指导是综合练习入口，拼写只是其中一种题型，不能把整个系统命名为“单词拼写”或“拼写训练”。

| 题型 | 练习内容 | 经营结合方式 |
|---|---|---|
| 词义理解 | 理解单词、短语及常见表达 | 理解食材、设施和工作相关词汇 |
| 词汇搭配 | 选择自然、正确的常见搭配 | 学习制作、服务和采购表达 |
| 语境选词 | 根据句子或短对话选择合适词语 | 理解菜单说明和工作情境 |
| 拼写 | 根据提示补全或输入单词 | 巩固已学词汇，作为可选题型 |
| 句子理解 | 理解句意、条件和信息关系 | 理解服务要求和经营说明 |

题目按当前学习内容和错题情况搭配，不固定为连续三次拼写。先理解再巩固，作答后提供正确答案、简短解析和关键表达；不同题型按学习量平衡奖励，不让某一种题型成为刷收益的唯一选择。

背单词作为英语指导中的常驻学习方式，支持新词学习、复习和错词巩固，复用已有词库与学习记录；不要求所有词都改写成餐饮词汇。首版先支持词义理解、词汇搭配、语境选词和已有拼写题型，句子理解后续扩展。界面使用“英语指导”作为入口名称，在单题中标明具体题型。与“真题听力研修”分别设置入口和练习记录；英语指导中的文字情境不得作为自编听力替代真题。

无需每做一盘菜都答题。普通经营本身持续成长，学习提供有意义的加速。词汇优先使用四六级常考词和常见搭配，在后续剧情与训练中复现；不因本方案重写已有剧情难度。

## 10. 四六级真题听力研修

### 硬性内容规则

听力必须使用四六级真题原录音及对应题目、选项和答案。不能用自编客人订单、员工对白或合成配音代替真题；不能改写真题来迁就酒馆设定。

按原试卷材料组织完整题组。同一段材料与其配套题目一起完成，不任意剪碎并拼成虚构订单。界面可以包装为员工研修，音频和题目内容保持真实。

### 学习入口与流程

营业中从同屏学习面板进入真题听力，酒馆场景继续显示并自动经营。选择四级或六级、年份、套卷和题组；难度选择与剧情章节分开，玩家可以长期练习同一级别。复用现有听力入口与数据，但进入后保持经营画面，不切换到遮满酒馆的独立考试页面。

选择厨师或服务员及题组 → 员工营业期间播放录音并答题 → 查看正确率与错题 → 所选员工获得额外经验 → 当前营业中看见成长效果 → 继续学习或调整经营。

提供题组练习及后续完整套卷练习。保留原材料内部顺序；切换题组不应漏掉必要的口播问题或截断内容。

### 两种模式

| 模式 | 行为 |
|---|---|
| 考试练习 | 按对应真题播放与作答安排进行，答题期间不显示原文、翻译和答案，不提供随意重听；题组练习明确标为练习，不能冒充完整模考 |
| 精听复习 | 支持重听、逐句播放、慢速、原文与翻译开关、单词查看及解析；初次答题和看答案后的订正分别记录 |

听力时经营计时和员工工作继续，自动关闭经营背景音乐、客人语音和明显工作音效，确保真题录音清晰。慢速、重听和逐句播放仅改变音频，不改变经营速度；保留原始录音。

考试练习期间经营事件不抢焦点、不播放提示音，升级和收入采用轻量视觉反馈。需要经营调整时可等题组结束再操作；用户若主动中断音频或离开考试流程，记录为中断练习，不把额外重听后的结果当作原条件下的成绩。精听模式可随时暂停录音处理经营，恢复时保留位置。

### 奖励与复习

- 完成完整题组提供基础员工经验，正确率提供额外经验；低分也能培养员工。
- 首次完成、首次纠错和后续复习分别记录，重复奖励递减或设置合理上限，避免刷同一组成为最佳经营策略。
- 查看原文、翻译或答案后完成的结果标为辅助练习，不覆盖独立作答成绩。
- 错题按原因和题组归档，优先推荐未练题组及需要复习的内容。
- 学习反馈在面板内先展示答题与解析，再显示员工成长，不用全屏结算遮住营业；员工经验奖励不要伪装成英语水平评价。
- 正常经营经验与学习进度分开保存。重要主线信息不依赖一次听力答对才能获得。

### 现有资源接入

后续优先复用该入口和资源，按此策划调整研修导航、模式和经营奖励。原始音频与对应时间轴必须匹配，不能混用不同录音版本。自动对齐字幕与辅助翻译需显示准确的来源性质，出现错误时可修订；题目和标准答案不得由识别或翻译模型补造。资源缺失时标为不可用，不生成伪真题。

来源、版本和材料记录随资源保留。项目现有说明指出资料的个人学习限制，下载不等于取得公开再分发或商业授权；发行资源范围需沿用项目现有许可管理。

## 11. 同屏学习与经营反馈

### 画面布局

默认酒馆占画面约六成，学习面板占约四成，具体比例随分辨率和题目长度调整。酒馆一侧始终可观察厨师、服务员和主要工作路线；学习一侧完整显示当前题干、选项、播放控制和学习进度。长听力材料和解析使用分页，不能为了保留场景截断题目。

提供“观察酒馆”和“专注学习”布局：前者扩大经营区域，后者扩大题目区域但保留实时酒馆视窗。切换保留答案、音频位置和任务状态；默认不使用覆盖全部场景的学习弹窗。学习面板输入焦点与经营快捷键分开，输入单词不会误触移动设施或加速。

### 两种学习对应两种经营收益

| 学习方式 | 直接收益 | 持续方式 |
|---|---|---|
| 英语指导／背单词 | 单次菜品品质或单次服务质量提高，对应订单赚取更多金币 | 使用一次即消耗，不增加永久属性 |
| 四六级真题听力研修 | 所选员工获得额外经验，升级提高能力、解锁技能 | 员工长期成长 |

英语指导完成一个短组后，自动给下一份符合条件的出品或下一次服务附加一次加成。首版优先实现“下一份菜品品质提升”：厨师仍按原流程制作，出品时显示指导标记，结账时显示该份菜增加的金币。后续可增加一次送餐或接待的服务加成；同一份奖励选择一种效果，不同时重复加菜品品质和服务收益。

加成按一次实际出品或服务消耗，不按现实秒数倒计时；当前没有合适订单时保留，跨日也保留。连续学习可积累有限次数，界面明确显示待用次数；临近上限时提示，并允许玩家继续学习，只是不再无限堆积经营奖励。具体上限与增幅通过试玩确定。加成不跳过制作、不凭空完成订单，也不直接增加员工经验或菜谱熟练度；额外金币可由玩家正常用于采购与设施升级。

听力开始前选定厨师或服务员为培养对象，整组完成后经验自动投入该员工，显示距下一等级或技能节点的进度。切换对象只影响之后开始的题组，同一题组不重复发奖。员工工作的基础经验独立积累，成长条分别标出工作经验和听力研修贡献。

员工升级在完成手头动作后生效，弹出短暂像素提示，不中断录音或弹出技能选择窗口。需要玩家选择的技能先保留为待选择状态，在题组间隙确认；已确认技能立即参与后续工作。

两类练习都保留完成与纠错反馈，并按重复练习情况控制经营奖励，不要求连续全对才能获得收益。学习记录和真题评分独立保存，不因经营奖励改变答案或成绩。
### 为连续学习设计的经营自动化

开店前允许设置库存补购上限、菜单缺料时停售及员工休息规则。首版至少保证已有库存足以支持一组正常听力，员工能自动收桌、补柴和休息；不能把玩家每隔十几秒补一次物资作为学习前提。

缺料时自动暂停对应菜品或启用已设定的替代菜单；无座时停止继续接入超量客人，已有等待按正常规则处理。提醒保留在消息栏，玩家没有立刻点击也不会额外受罚。特殊订单在题组结束后给予完整决策时间，不能听录音时悄悄过期。

自动经营的瓶颈仍会影响收入和评价，让布局与培养有价值；控制损失和任务频率，使玩家可以完成一组真题后再调整。重大剧情始终等待学习边界或玩家主动打开。

### 一段实际体验示例

玩家先布置厨房、选择菜单，然后开店。学习面板开始词汇复习，场景里的厨师切配、服务员送餐。完成一组英语指导后，下一份菜获得一次品质加成；玩家看见优质出品被送到桌上，结账获得额外金币。

接着玩家选定服务员为培养对象，开始一组六级长对话真题。背景声音关闭，两名员工继续工作，金币与工作经验持续积累；营业事件进入消息栏。整组完成后查看解析，听力奖励经验推动服务员达到技能节点。玩家在间隙选择双盘送餐，随后继续学习，并能看到服务员一次端出两盘、等待队伍缩短。

## 12. 界面要求

- 经营主视图突出场景，常驻信息控制为金币、营业时段、当日目标和简短警报。
- 点击员工查看等级、能力、岗位、技能、疲劳及下一次成长；点击设施查看产能、积压与升级效果。
- 客人气泡和员工动作解释当前状态，颜色之外配合图标或文字表达。
- 学习、结算、员工和设施等同类弹窗采用战斗答题框的深绿金边样式。
- 使用通用 PixelFrame 阶梯形裁切，去除外侧四角黑矩形和内部黑底，关闭按钮为金色像素样式。
- 长内容采用分页、自适应布局或符合游戏风格的交互，禁止 Windows 默认滚动条，也不能隐藏后截断内容。
- 不把实现细节、内部资源编号和技术诊断信息放进常规玩家流程。

## 13. 第一版范围

目标是提供可体验三至五个营业日的完整成长循环。

| 系统 | 首版内容 |
|---|---|
| 场景 | 一楼大厅、吧台和厨房，固定视角 |
| 员工 | 厨师和服务员两人，不含男主；四项能力、每人一个特长、五级成长 |
| 技能 | 三级和五级各一次可观察成长 |
| 容量 | 四张餐桌，基础厨房设施 |
| 菜单 | 两种食材、三道菜和简单饮品；名称结合既有剧情确定 |
| 工作 | 拿料、切配、烹饪、装盘、送餐、结账、清理 |
| 客人 | 镇民、冒险者、一个熟客与一个特殊订单事件 |
| 布局 | 移动部分设施、距离影响、通路检查 |
| 成长 | 每日目标、经验、菜谱熟练度、基础设施升级 |
| 英语指导 | 营业中同屏背单词、复习及多题型指导，奖励单次菜品品质与对应额外金币 |
| 听力 | 营业中同屏真题练习与精听，音频避让、事件延后、成绩记录及额外员工经验 |

首版暂不加入自由建造整栋建筑、完整住宿模拟、陈酿生产链、大量性格组合和复杂搭档系统。已有听力资源不因经营首版规模小而删除。

## 14. 后续扩展顺序

1. 完善熟客、菜谱差异、商人和预约订单，让经营方向形成取舍。
2. 开放酒窖、陈酿与采购机会，以库存和设施管理为主，饮品出餐仍由服务员承担。
3. 开放二层环形客房与简化住宿经营；入住、退房和客房状态通过系统处理，不增加客房服务岗位或独立客房劳动流程。早餐沿用厨房制作与服务员送餐流程。
4. 增加员工搭档、专属技能和角色小故事。
5. 完善听力完整套卷练习、错题复习安排和长期学习统计。

扩展沿用同一经营循环，每次引入少量新需求与解决方式，避免多个系统同时压给玩家。

## 15. 试玩验收标准

- 玩家能从画面判断一次典型积压的原因，而不是只知道满意度下降。
- 第一晚厨师和服务员两人有明显瓶颈；调整出餐台、优化服务员送餐与收桌的任务优先级、解锁双盘送餐后，同样两人管理四张桌子的运行明显改善。
- 员工技能改变可观察行为；菜谱和设施成长有各自价值。
- 连续三至五个营业日都有新的成果或接近完成的目标，且无需强制反复答题才能维持生意。
- 真题音频、题组、选项与答案匹配；考试与精听记录区分，辅助操作不会污染独立作答成绩。
- 英语指导和真题听力均能在营业中进入，默认不暂停经营；题目显示时仍能看见两名员工实际工作。
- 完成一组真题期间无需强制处理经营点击，经营提示不抢焦点、不干扰录音，特殊订单不因学习而过期。
- 英语指导只产生一次性品质或服务加成，对应订单的额外金币可见，不直接增加员工经验、永久能力或菜谱熟练度。
- 真题听力直接增加所选员工经验，升级和技能生效后的行为变化在当前营业可见，不必等打烊或次日。
- 营业日结束不截断音频、不清空答案；题组结束后能够结算并沿用安排继续营业。
- 学习布局、输入焦点、音频与经营速度独立，慢速与重听不会误改变经营状态。
- 暂停、区域切换、布局调整和学习不会丢失订单或破坏员工任务；存档能保留经营与学习进度。
- 各分辨率下界面内容可读、可访问，无默认滚动条、弹窗黑角或被截断题目。

最终要验证的体验：玩家亲眼看着自己培养的员工更熟练、分工更顺畅、酒馆更热闹；同时通过真实四六级材料持续学习，而不是把经营变成每一步都要答题的流程。
