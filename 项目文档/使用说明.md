# 六级物语 · 使用说明

双击 `Cet6Story.exe` 运行。请保留整个文件夹，图片、配音、词典和章节依赖旁边的资源目录。需要 Windows 与 .NET Framework 4.x，无需联网。

## 主线听力

目前开放第一卷第一章，包含雨夜追踪、地下末班车、失名档案、黎明信号四节，采用原创赛博朋克情境与四六级学习词汇，不是考试原文或考试原音。新玩家进入第一节时直接显示规则页。点击右上角关闭按钮进入本节词汇准备，点击规则图本身不会跳转。

- 每题对应剧情首次听不显示字幕；逐句和连续播放都会在题目处进入选择。
- 语音结束后点击场景推进并播放下一句。“前一句”和“后一句”也直接播放。
- 无论回答是否正确，都可返回本题剧情开头重听，重听可开英文字幕。整节结束后的复习可以显示中文字幕。
- 答案和解析在整节结束统一显示。
- 未全部答对为一星；全对为两星；全对且本节总用时不超过五分钟为三星。重听计入总时间，但不会直接限制为两星；重新闯关才重置计时。
- 至少两星解锁后续小节。1.2、1.3、1.4 分别需要使用对应的商店道具。

## 背单词 · 词域远征

主菜单点击“背单词”进入像素风远征大厅。每局八层分叉地图，点击相连的亮起节点。通过词义选择、反向选词、例句填空和拼写发动攻击；小怪赚金币，精英获得赋能，火堆恢复或加攻击，问号事件与宝箱提供不同奖励，最终挑战首领。地图只显示路线与节点，战斗使用森林、石殿、熔火峡谷的新背景与怪物，加入攻击、受击及伤害数字特效。

内置 143 个学习词条与原创例句，并非完整四六级词库。根据词义选词、语境填空在答题时无法播放目标单词发音，提交后可在本回合反馈中播放；反馈同时显示英文例句和中文译文。可选基础、进阶、六级挑战，也可用自己的生词本开始。错词自动收集；生词本支持筛选、分页、发音和间隔复习。

金币统一用于地图商店、成长商店和主线系统商店。旧版未完成远征的补给币进入新模块时一次性转换为金币。成长升级与地图赋能作用于单词远征，系统商店道具用于主线剧情。详细玩法见 [词域远征-玩法说明.md](词域远征-玩法说明.md)。

## 操作与存档

主线剧情下方的倍速按钮显示当前速度，每点击一次按 0.5x → 1.0x → 1.25x → 1.5x → 0.5x 循环切换，不弹出菜单。内置配音保留音调，切换时接着当前播放位置，暂停时切换仍保持暂停。速度自动保存；整节评分仍按实际用时计时。单词发音不受主线倍速影响。

倍速处理依赖随游戏附带的 `tools/ffmpeg`，请保留此目录。首次导入的新音频会生成倍速缓存，之后复用。

- 单词选择题按数字键 1–4；拼写输入后按 Enter；反馈页按 Enter 继续。
- F11 或 Alt+Enter 切换全屏，拖动窗口边缘调整大小；小窗口内的单词卡片可以滚动查看。
- `save.json` 保存剧情、星级、生词、金币、成长升级和未完成远征。答题、路线选择和购买后自动保存，退出后可继续本局。
- “新游戏”重置主线，保留生词和单词远征成长。请勿删除或用旧存档覆盖已有学习记录。

本次更新保留已有存档，直接更新当前目录程序，没有重新打包。

## 一键分享打包

双击本目录的 `一键打包.bat`，生成的 ZIP 位于 `打包输出` 文件夹。无需 Python 或额外压缩软件。每次生成独立文件，不覆盖旧包。

分享包包含当前程序、剧情、配音、图片、词库、说明和倍速工具；排除源码、概念稿、测试目录、音频缓存以及个人存档。原有 `save.json` 不会被删除或修改。收件人完整解压后运行 `Cet6Story.exe`，首次运行自动建立新存档。

如果要备份自己的进度，可在 PowerShell 中执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\一键打包.ps1 -IncludeSave`。包含个人存档的包请自行保管。

计时按剧情界面的实际停留时长累计：首次播放开始，每秒刷新；离开到主菜单、章节、商店或背单词页面后暂停，返回剧情自动继续，关闭游戏期间不计时。剧情内重听、语音暂停与答题仍计时，最后一题提交后冻结。旧存档保留已有用时，重新闯关可以清零。


## 本节词汇准备

第一章四节分别配有24个核心词。先看词卡或直接进入独立准备战斗，每词在两种不同题型中无提示答对后计为已准备；进度跨局保存，战败也不清空，错词自动收藏。根据词义选词和填空不自动发音。

每词每日首次无提示答对3金币；首次整节准备完成额外60金币，重复点击不领奖。若24词当日都尚未领奖，首次准备共132金币。此前训练已领过的词不会重复发每日金币。

第一节新增临时身份屏蔽器，120金币。准备完成后到系统商店购买，再点击部署进入第一节。后三节也先完成各自准备，再使用原有对应道具；听力两星要求保持。准备与普通肉鸽远征各自保存；准备、购物不计听力时间。

更新前已实际进入台词、听过或完成的小节保持访问权限，不强制补做准备。新的未游玩小节使用新准备流程。原有金币、收藏与已激活道具保留。

远征大厅新增“本节词库”，可在分叉地图中练习本节核心词，与独立词汇准备共享掌握进度；每词需在两种题型中无提示答对。已经获得的金币和学习记录在战败后保留。

## 背单词音乐与音效

单词远征和本节词汇准备使用原创像素风背景音乐，40 秒循环；攻击、受击音效随动画触发。单词发音时音乐自动降至当前音量的 20%，结束后恢复。切换地图、战斗或反馈不会重头播放；退出背单词界面会停止音乐。设置页可分别调整背景音乐、音效音量，调至 0 即静音，不影响语音音量。音频随游戏资源一起打包，无需联网。
