# 队伍战斗技能重设计 v2

2026-10-06设计提案。本文重新设计陆川、艾莉娅及蘑菇林地九种怪物，尚未替换现有战斗代码；数值为首轮平衡基线。

参考《暗黑地牢》一代的站位限制、持续伤害与职业分工，以及二代的可消耗状态标记和连携。采用本游戏自己的言契、角色身份及学习反馈，不照搬压力崩溃、死亡之门或整套职业。

## 基础规则

- 每方四格：我方从右到左编号1、2、3、4，敌方从左到右编号1、2、3、4；双方1号位最靠近中央，4号位最后。一单位一格，格子序号固定，空位不导致单位自动换位。前排为1—2，后排为3—4。
- 每个单位每回合一次行动，按速度排序；艾莉娅速度3，陆川速度4。初始建议艾莉娅2号、陆川3号。每人8项候选技能，携带5项。没有合法目标的技能禁用；通用移动可移动一格或与相邻友军交换，消耗行动。
- 英雄主动技能一动作只答一次题，群体技能不逐目标答题。答对执行完整效果；答错直接伤害、治疗、护盾数值减半（向下取整），不新增附加状态、不触发或消耗决意/符印、不打断或位移，但正常消耗行动、冷却与使用次数。既有强力、虚弱、失准等攻击标记照常消耗。攻击造成伤害至少1点。
- 敌人一动作只触发一次防御题，包括群攻。答对该动作对所有受击友军直接伤害减半；答错承受完整直接伤害。附加状态按技能正常施加；闪避目标不受直接伤害或新状态。守护重定向先于防御题，不重复出题。
- 冷却写成“间隔”：间隔1表示接下来一次本单位行动不能用，之后可用；技能使用后不立即递减其新冷却。每战使用次数不因换位置或复活重置。
- 同技能重复施加计数标记按上限叠加；同来源持续伤害刷新回合，不叠强度。不同来源最多保留两份独立持续伤害，每份单独计时。界面显示例如“流血3×2回合”。
- 持续伤害在受影响单位开始行动时结算，即使其吟唱或失去行动也结算。恢复优先于持续伤害，生命归零立即倒下。状态不以界面刷新或答题耗时递减。
- 直接伤害百分比以施法者攻击力为基准；群攻百分比为每目标数值。强力/虚弱/失准先改变伤害，易伤再改变承伤，格挡随后减伤，最后扣除数值护盾。

## 正面效果：6种

| 效果 | 规则 | 上限／失效 |
| --- | --- | --- |
| 格挡 | 下一次受到直接伤害减少50%，不减持续伤害 | 最多2枚；每次受攻击消耗1枚，未触发最多保留至第二次自身行动结束 |
| 闪避 | 下一次敌方攻击有50%概率躲开；成功则该次直接伤害和附加状态均不生效 | 最多2枚；无论成功失败都消耗1枚，最多保留至第二次自身行动结束 |
| 强力 | 下一次伤害技能直接伤害增加50%，不提高持续伤害 | 最多2枚；群攻整次只消耗1枚，最多保留至第二次自身行动结束 |
| 守护 | 由施加者替指定队友承受下一次单体攻击 | 一条关系，不叠加；守护者不能再被其他单位守护，群攻不转移；至守护者下次行动结束过期 |
| 反击 | 被敌方伤害攻击命中后，反击其攻击者，造成自身攻击力40%伤害；该次被护盾完全吸收也可触发 | 最多2次，至第二次自身行动结束过期；不反击持续伤害或反击，不新增答题 |
| 不退 | 免疫推拉和强制交换位置 | 持续至下一次自身行动结束；不限制主动移动 |

保留数值护盾作为吸收伤害资源，跨回合保留、上限最大生命40%。格挡与护盾是不同机制，不再同一按钮同时显示成“护盾”。

## 负面效果：8种

| 效果 | 规则 | 上限／失效 |
| --- | --- | --- |
| 虚弱 | 下一次伤害技能直接伤害减少50% | 最多2枚；群攻整次消耗1枚，最多保留至第二次自身行动结束 |
| 易伤 | 下一次受到直接伤害增加50% | 最多2枚；不提高持续伤害，最多保留至第二次自身行动结束 |
| 失准 | 下一次伤害技能直接伤害减少50%，不随机整次落空 | 最多1枚；与虚弱同时存在时总减伤封顶50%，两者都消耗；最多保留至第二次自身行动结束 |
| 流血 | 开始行动时受到技能指定的生命伤害，穿透护盾与格挡 | 通常2—3次；“流血3×2”表示每次3点，共两次 |
| 菌毒 | 开始行动时受到技能指定的生命伤害，穿透护盾与格挡 | 通常3次；用作蘑菇林地的主要持续伤害 |
| 灼烧 | 开始行动时受到技能指定的生命伤害，穿透护盾与格挡 | 通常2次；与流血、菌毒可共存 |
| 迟缓 | 下一回合速度降低2 | 刷新不叠加；已经排好的本回合顺序不改变 |
| 封咒 | 下一次选行动时禁止带“法术/增益/治疗”标签的技能，可以攻击或移动 | 最多1枚；该次行动结束解除，并立即打断法术吟唱；不阻止物理炮筒装填 |

暂不加入普通眩晕，以免连续跳过行动导致压倒性控制；“打断”只取消已预告的准备，不自动让对方跳过下一次行动。

## 专属资源与准备状态

- 艾莉娅的**决意**：护盾或格挡实际减少一次敌方直接伤害，获得1点，每敌方动作最多1点，最多3点。不同攻击技能以不同方式消耗；没有“所有攻击自动清空决意”的规则。
- 陆川的**符印**：目标身上最多3层；最近施加后可保留至其第三次行动结束。引爆每层加伤，剑盾技能可消耗1层产生连携。两人或敌方不能消费对方阵营施加的符印；目前林地敌人不使用英雄符印资源。
- **吟唱／装填**：可见准备状态，显示剩余行动数及目标范围，不算正面效果。用一次行动准备，下次自身行动才释放，绝不能同回合连开。中途若被带打断标签的技能命中，取消准备，下一次可以重新选择普通行动。
- **瞄准**：树蜥的可见锁定提示；不叠加、不额外增伤于其他怪物，只供其下一次瞄准射击使用；树蜥改目标、被打断或倒下即解除。

## 首批遭遇与上线顺序

1. 序幕：仅荆棘孢子兽，先展示单体攻击与扎根，再展示菌毒；按教程阶段解锁AI，不直接把九种怪全部塞进开场。
2. 林路：角鹿＋树蜥，认识推位与瞄准。
3. 林间暗处：孢子兽＋螳螂＋菌蛾，练习守护后排、叠印打断。
4. 溪岸：搬运蟹＋炮菇蟾＋水母，准备／散热期间集中输出；前三场尚未教过的状态先提示。
5. 深林：合唱伞灵＋角鹿，群体菌毒与治疗资源管理。

双人队伍普通遭遇先以两只怪为主，三怪作为后续高难遭遇，不默认四怪满阵。对局允许持久但不鼓励无限治疗；装填、瞄准、守护均显示明确图标与目标线。

## 实施边界

本稿提出速度轮转、八项候选技能、格挡/闪避标记、菌毒等新规则，现有代码不具备完整实现。落地需更新状态结算、敌方AI、技能选取与目标范围、站位校验、旧存档技能映射、答题流程和战斗提示。现有护盾、决意、符印需迁移，不能仅改技能说明造成显示与实效不一致。旧技能可按原ID保留兼容别名，但移除技能应自动回填合法初始技能，不改玩家剧情存档。
