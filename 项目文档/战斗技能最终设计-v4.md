# 战斗技能重设计 v4：用途、代价与配合

2026-10-06。当前最新策划稿，覆盖v2/v3冲突处。尚未替换游戏代码、技能图标或玩家配置。数值为测试起点，不是经过实战验证的最终平衡。

## 战场和行动

屏幕从左到右：我方【4】【3】【2】【1】｜敌方【1】【2】【3】【4】。1号靠中央，每单位一格。黄色实心圆点代表能释放技能的自身位置；蓝色实心圆点代表合法目标位置；空心代表不适用。蓝点不连线为单体任选，蓝点连线为固定群攻。自身/友方技能明确标注目标阵营；圆点排列与对应阵营在屏幕上的顺序一致，附小号编号。

双方按速度排入同一个队列，每回合每单位一次行动。速度：艾莉娅4、陆川6、孢子兽2、菌蛾7、伞灵5、炮蟾1、搬运蟹2。同速奇数回合我方先，偶数敌方先，同阵营同速按回合开始位置1→4。队列本回合固定，死亡移除，速度变化下回合生效。右上角显示行动中头像、其后未行动队列、速度与位置、准备图标，区别已行动历史与下一回合预测。

通用移动占用行动，可移一格或交换相邻存活同阵营单位。强制拉近为编号-1，推远为+1；不跨阵营、不跨出四格。普通倒下单位退出格子，暂不加入尸体机制。带主动移动技能必须有合法目的格才能选；攻击附带强制位移若不能移，攻击仍执行。群攻空格跳过，不改打其他位置。

## 状态系统精简

### 六种正面标记

| 状态 | 规则 |
| --- | --- |
| 格挡 | 下次受到直接伤害-50%，最多2枚；不减持续伤害 |
| 闪避 | 下次受攻击有50%概率完全避开，成功也避免附加状态；无论成功失败消耗，最多2枚 |
| 强力 | 下一次伤害技能直接伤害+50%，整次群攻只消耗1枚，最多2枚 |
| 守护 | 施加者替一名队友承受下次单体攻击；不转移群攻；一条关系，禁止守护链 |
| 反击 | 被敌方直接伤害攻击命中后反击，威力由技能指定；护盾全吸收也触发，不反击持续伤害或反击 |
| 不退 | 免疫强制推拉，仍能主动移动 |

格挡、闪避、强力未触发至第二次后续自身行动结束过期。守护、反击、不退至施加者下一次后续行动结束过期。施加当次行动结束不递减。保留数值护盾为独立资源，吸收剩余直接伤害，上限最大生命40%，跨回合保存。

### 七种负面标记

| 状态 | 规则 |
| --- | --- |
| 虚弱 | 下一次伤害技能直接伤害-50%，整次群攻只消耗1枚，最多2枚 |
| 易伤 | 下一次受直接伤害+50%，不增持续伤害，最多2枚 |
| 流血 | 自身行动开始扣技能指定生命，穿透格挡和护盾 |
| 菌毒 | 同时点持续伤害，蘑菇林地主要威胁 |
| 灼烧 | 同时点持续伤害，菌蛾的腐光烧灼体现其单体威胁 |
| 迟缓 | 下一回合速度-2，最低1；刷新不叠加，不改本回合队列 |
| 封咒 | 下一次行动不能选法术、增益、治疗技能，可以攻击或移动；立即取消法术准备，不取消物理装填/瞄准；该次行动结束解除 |

删去旧方案中与虚弱重复的“失准”，避免两套图标做同一件事。虚弱、易伤至第二次后续自身行动结束过期。持续伤害“3×2”表示每次3点共两次；同技能同施加者刷新，不叠强度，不同来源最多两份各自计时。群体持续伤害应低于单体持续伤害。每单位行动开始结算，倒下立刻退出队列。

## 两人的专属资源

- **决意**：艾莉娅用格挡或数值护盾实际减免一次敌方伤害，获得1点，每敌方动作最多1点，上限3。技能明确选择是否消费，不再全部攻击自动清空。
- **符印**：陆川施加在目标上，上限3；至目标第三次后续行动结束失效，重新施加刷新。既能确保攻击命中、移除防御，也能引爆。只有注明消费的英雄技能才消费，敌人不使用此资源。
- 没有常驻嘲讽，不保证怪物一定攻击坦克；需要通过守护、选目标、站位与敌人意图判断保护对象。

## 艾莉娅：十选五（原八招与文末新增两招）

身份是能保护伙伴的前排骑士。技能包含普通输出、持续伤害、破防控制、救场换位、守护、反击、资源爆发和自救；不做八种带护盾的攻击。

| 技能 | 黄点施法 | 蓝点目标 | 答对完整效果 | 代价／作用 |
| --- | --- | --- | --- | --- |
| 骑士斩击 | 1/2/3 | 敌1/2单体 | 100%直接伤害；若有符印消费1层，本次忽略闪避 | 无间隔；可靠基础进攻，不附护盾。无符印则正常检查闪避 |
| 裂伤剑锋 | 1/2 | 敌1/2单体 | 50%直接伤害，流血3×3 | 无间隔；处理厚格挡，不能穿透格挡的直接部分；符印不消费 |
| 盾击破阵 | 1/2 | 敌1/2/3单体 | 35%直接伤害；伤害前移除1格挡，命中后打断准备；若有符印再消费1层移除第二枚格挡 | 间隔1；低伤换破防/打断，不同时附易伤；闪避成功则不打断也不消费符印，已在命中前移除的格挡不退回 |
| 守护誓言 | 1/2/3/4 | 任意其他友军 | 守护其下次单体攻击，自身获得1格挡 | 间隔1；看敌方锁定再保护，群攻不转移 |
| 架盾反击 | 1/2 | 自身 | 获得2次反击，每次50%攻击力 | 间隔2；没有格挡或不退，承担受击风险，不能通过反击消费符印/决意 |
| 挺身突进 | 2/3/4 | 敌1/2单体 | 前移一格，75%伤害；消费1点决意获得不退，没有决意仅移动与伤害 | 间隔1；恢复站位而非泛用增益技；不额外加格挡 |
| 决意斩杀 | 1/2 | 敌1/2单体 | 100%＋每点决意25个百分点；若目标生命≤30%再+25个百分点，最多200% | 至少2点决意可用，消费全部；间隔2；目标厚格挡仍会减伤 |
| 坚韧整备 | 1/2/3/4 | 自身 | 恢复20%最大生命，清除全部流血与菌毒 | 自身生命≤40%，每战2次；不附格挡、不清灼烧；用一次行动放弃输出 |

推荐入门：斩击、裂伤、破阵、守护、突进。反击与斩杀是可换入的路线，整备按区域持续伤害压力决定。

### 技能精通方向（每项最多精通一次，不改基础功能）

斩击：消费符印命中后再给自身1格挡。裂伤：流血每次由3提高到4。破阵：可攻击位置增加敌4。守护：获得2格挡而非1。反击：每次50%提升到60%。突进：不再需要决意即可获得不退。斩杀：低血阈值30%提高到40%。整备：恢复20%提高到25%，同时解除灼烧。精通点稀缺，不能开场全技能升级。

## 陆川：十选五（原八招与文末新增两招）

身份是擅长分析和安排言契的术士。叠印技能本身不高伤，兑现技能需要准备；加入牵引，让他主动为艾莉娅创造可打目标，而不是只做另一名射手。

| 技能 | 黄点施法 | 蓝点目标 | 答对完整效果 | 代价／作用 |
| --- | --- | --- | --- | --- |
| 言契冲击 | 2/3/4 | 敌1/2/3/4单体 | 80%直接伤害；消费1层已有符印时无视闪避 | 无间隔；不再自动叠印，普通攻击不能兼任最强准备技 |
| 铭刻符印 | 2/3 | 敌1/2/3/4单体 | 施加2层符印，无直接伤害；不受闪避影响，也不消耗闪避 | 无间隔；明确放弃当次伤害换后续选择，不是所有附状态技都必中 |
| 符印引爆 | 3/4 | 敌1/2/3/4单体 | 50%＋每层符印30个百分点，消费全部，最高140%；本次不触发闪避 | 至少2层符印可用；间隔1；格挡照常减伤，不能一键绕过所有防御 |
| 言契牵引 | 2/3 | 敌3/4单体 | 25%伤害，拉近一格；有符印消费1层，再施加易伤1枚 | 间隔1；移位有不退等免疫时不消费符印、不附易伤；4号可拉至3号让盾击够到 |
| 符文震荡 | 4 | 敌3—4连线 | 各35%直接伤害；每个被命中目标获得1层符印 | 间隔1；后排拆闪避与群体铺印，不能代替单体铭刻的速度；每目标单独闪避 |
| 禁言封咒 | 3/4 | 敌2/3/4单体 | 无直接伤害；消费1层符印施加封咒，并取消正在进行的法术准备；不受闪避影响 | 需要已有符印；间隔2；无符印禁用，不附备用虚弱。不能阻止物理炮装填 |
| 共鸣屏障 | 2/3 | 任意友军单体含自身 | 给目标1格挡，清除其1枚虚弱；有数值护盾时仍仅给格挡 | 间隔1；去掉同时叠印强化与多种净化，专门应对下一次直伤 |
| 应急包扎 | 1/2/3 | 任意友军单体含自身 | 恢复20%最大生命，并清除全部流血；若其有菌毒则还清除剩余伤害最高的一份菌毒 | 目标生命≤50%，每战2次；灼烧需其他对策，持续伤害结算发生在治疗前的行动者不能靠事后治疗复活 |

推荐入门：站3号位，装配冲击、铭刻、牵引、屏障、包扎。后排群攻换入震荡并站4号位，代价是不能铭刻、牵引、屏障或包扎；可用冲击、引爆、震荡、封咒、余烬组成4号位输出装配，但符印需先在3号位准备或由震荡铺设。爆发／法师战可在3号位换入引爆／封咒。通用移动仍占一次行动，不能免费换位规避限制。

### 技能精通方向

冲击：消费符印时威力80%提高到100%。铭刻：额外清除目标1枚闪避，仍不造成伤害。引爆：每层30提高到40个百分点，最高170%。牵引：成功拉近即附易伤，不再消费符印。震荡：伤害35提高到45%。封咒：间隔2缩短为1。屏障：额外清除1枚易伤。包扎：解除菌毒改为全部菌毒。技能仍保留站位与次数等其他限制。

## 怪物：独立问题与反制

下表每项分别写黄点施法位置→蓝点目标位置；“全体”表示1—2—3—4连线。“自身”不显示敌方目标。直伤百分比按该怪攻击力计算。基础敌攻击设为同级陆川攻击的70%作测试起点，高速度并不同时意味着最高攻击。当前仅保留五种：孢子兽生命为同级艾莉娅1.1倍、蛾0.5、伞灵0.6、蟾0.9、蟹1.4；具体遭遇需实测。

### 荆棘孢子兽：前排战士，速度2

- **棘牙撕咬**：黄1/2→蓝敌1/2任选；90%＋流血2×2。
- **扎根甲壳**：黄任意→自身；2格挡＋不退，间隔2。维持前排但不永久免疫位移。
- **孢囊破裂**：黄1/2/3→蓝敌1—2连线；各35%＋菌毒2×2，间隔1。
- **反制**：伤害主要压前排；裂伤穿过格挡持续扣血，破阵拆防，治疗次数要分配。序幕教程首次根甲只1格挡，后续正规遭遇才2枚。

### 灯笼菌蛾：快速单体法师，速度7

- **萤孢烙印**：黄2/3/4→蓝敌任意单体；30%＋易伤1枚。
- **灯囊聚光**：黄3/4→蓝敌任意锁定；消耗行动准备，预告目标。
- **腐光射线**：黄3/4→已锁定单位；下一回合该单位行动时130%＋灼烧3×2，消耗准备。
- **振翅移栖**：黄1/2/3→自身；后移1格，1闪避，间隔2。
- **反制**：守护锁定对象，叠印封咒，牵引到非法站位取消准备。准备不额外自带闪避，避免多重保护无解。非准备轮烙印与移栖之间可选。

### 合唱伞灵：增益吟游诗人，速度5

- **振奋菌歌**：黄3/4→蓝其他友方1/2/3/4任选；给予1枚强力，间隔1。不对自身使用；目标强力已达上限则不可选。
- **护根和声**：黄2/3/4→蓝友方1/2/3/4任选（含自身）；给予1枚格挡，间隔1；已达上限不可选。
- **清音回响**：黄3/4→蓝友方任意单体；移除1枚虚弱或1枚易伤，优先虚弱，间隔1；无可净化状态不可选。不清除符印或持续伤害，不治疗。
- **根须抽击**：黄1/2→蓝敌1/2任选；40%直伤，无附加状态。被拉到前排后只能弱攻击、护根或通用后移。
- **反制**：优先封咒或拉到1号位关闭增益；2号位仍能护根但不能强力或净化。封咒可阻止上述三种增益法术。独自存活时不能给自己强力，主要攻击威胁低。
- **行动选择**：每次只能唱一种歌，不同时叠加强力与格挡；优先为将要攻击且没有强力的队友振奋，其次给受威胁者格挡，再净化。没有合法增益目标且处于后排时通用前移，不允许无目标空放或无限等待。速度5让炮蟾装填后通常能在下一回合开炮前得到强力，但英雄也有一轮反制窗口。
### 鼓腹炮菇蟾：低速群体炮手，速度1

- **鼓腹装填**：黄3/4→自身准备；消耗一次完整行动，显示炮口聚光与全体目标线。
- **孢弹齐射**：黄3/4→蓝敌全体连线；下回合自身行动各60%直伤，无菌毒、虚弱等附加状态。
- **排气散热**：黄任意→自身；开炮后下一次行动必须散热，自身易伤1枚。
- **近身喷菌**：黄1/2→蓝敌1—2连线；各25%＋菌毒1×2。
- **反制**：稳定装填→炮击→散热，不能连炮；牵引4号至3号后，未精通盾击即可打断；封咒不阻止物理装填。群炮不可用守护替挡，需群体减压、击杀或打断，单体屏障只能保护一个队友。

### 苔壳搬运蟹：高血保护坦克，速度2

- **树桩护背**：黄任意→自身2格挡，间隔2。
- **横钳护送**：黄1/2→蓝友3/4任选；守护其下一次单体攻击，不额外给自身格挡，间隔1。
- **碎石钳击**：黄1/2→蓝敌1/2任选；60%＋虚弱1枚，间隔1。
- **反制**：单体控制也会被守护重定向；震荡群攻可绕过保护。拉后排施法者时必须先确认其是否被守护，不能假设牵引永远成功。蟹的自我格挡与守护需各花一次行动。

## 规则闭合与学习反馈

1. 正式行动开始先结算持续伤害和倒下，再检查准备与合法技能；行动结束推进队列。准备需下回合再次轮到自己才能释放，不加额外行动。
2. 锁定跟踪单位，非格子；锁定者倒下取消准备，下次可正常选技；准备者被移动到非法施法位立即取消，移回不能恢复。取消不额外扣其下一次正常行动。封咒只能打断法术，带打断标签的盾击能打断物理和法术。
3. 无视闪避攻击不消耗闪避枚数；明写移除才移除。符印技能消费条件发生在命中/位移成功的指定时点。必中只免疫闪避，不绕过守护或格挡。
4. 英雄群攻一题，敌群攻一次防御题。答对完整效果；答错直接伤害/治疗/数值护盾减半，不新增状态、叠印、净化、移动、打断或消费专属资源，照常消耗技能行动、冷却和使用次数；无直接伤害的准备/保护技答错无附加效果。技能会明确预告这一点。原有强力/虚弱仍按实际攻击消耗。
5. 敌方防御题答对该动作全部直接伤害减半，答错完整；技能状态照常施加，躲开的目标不受伤或新状态。反击无额外题，不触发其他反击，不插正式行动。
6. 伤害按攻击力×技能倍率，强力/虚弱→易伤→格挡→数值护盾顺序处理，向下取整。数值与概率分别显示，不用一个总伤害数字掩盖持续伤害。
7. 间隔1表示接下来一次自身行动不能用，之后恢复，间隔2对应两次。每战次数不受换位或保存读取重置。
8. 技能卡包含：名称／类型，黄蓝圆点，直伤与持续伤害，资源需求／间隔／次数，连携，精通变化。灰按钮必须解释是站位、资源、冷却、目标为空还是次数耗尽。

## 装配与遭遇检验

- 单人能做什么与队伍缺口同时明确：只有两位英雄时没有群体治疗，群炮威胁靠打断或击杀应对；持久战消耗有限包扎，不做无限回血。
- 每次普通遭遇优先两怪；三怪作为进阶，不能拿完整四怪阵测试后宣布双人初期平衡。
- 厚甲战：裂伤与破阵；法师战：铭刻+封咒，或牵引取消准备；吟游诗人战：封咒停增益或拉至前排；炮阵：牵引+盾击、震荡绕护卫。
- 常见选择必须存在代价：引爆消耗的符印不能再给骑士命中；带牵引会占用爆发/治疗槽；每次保护都会少一次攻击；慢速敌也能靠血量与护卫保证完成准备。
- 实现后测试单体/群体圆点、空格、移位失效、守护重定向、同速轮换、标记时限、资源消费与旧存档技能回填。不能仅改文字替代这些规则。

## 旧方案差异

保留角色身份、站位圆点、速度队列；取消普通攻击自动给多重收益。陆川用牵引替换封印灼痕，艾莉娅八技能保留但分工重做。移除重复负面状态失准。改为每种敌人制造一个主要问题，强招有准备/范围/资源/次数限制。此文为最新规范，前文冲突处以本稿为准。

### 新技能精通与结算

- 横扫剑弧：精通后每目标伤害升至65%。两目标独立判定闪避、格挡和守护（群攻不触发守护）；强力或虚弱只消耗一枚并作用于整次攻击，空位跳过，不转打后排。
- 誓约激励：精通后施加强力前额外移除目标1枚虚弱。基础版本仍可对虚弱队友使用，但强力与虚弱按原规则一起结算；强力上限2枚，目标已满且无可移除虚弱时不能使用，避免白花决意。只在答对且实际产生效果时扣除决意。
- 灼印余烬：精通后灼烧升至4×3。灼烧不是直接伤害，不受强力、虚弱、易伤、格挡或数值护盾加减，按目标行动开始结算。闪避成功则既无直伤也无灼烧。
- 折跃退避：精通后同时移除自身1枚虚弱；不增加移动距离，不增加闪避枚数。答错不移动、不新增闪避、不净化，照常消耗行动并进入间隔。
- 四招统一遵守正文答题与间隔规则；不新增状态种类，不提高装配槽位。誓约激励不能在只有施法者存活时使用。

## 五种怪物范围确认（2026-10-07）

当前蘑菇林地只制作荆棘孢子兽（战士）、苔壳搬运蟹（坦克）、灯笼菌蛾（法师）、合唱伞灵（增益吟游诗人）、鼓腹炮菇蟾（炮手）。炮手与弓手二选一，本版采用需要一回合装填的炮手。原九种总览图是历史外形参考，不代表现行制作清单；伞冠角鹿、影褶螳螂、针孢树蜥、涡伞水母暂不制作、不进入遭遇。以上五种复用现有形象，伞灵由群体法师改为增益辅助。暂不改动其他主线地点尚未确认的设计。
