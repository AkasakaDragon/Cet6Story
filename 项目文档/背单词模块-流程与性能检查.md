# 背单词模块流程与性能检查

本次覆盖四级/六级远征、本节词汇准备、出牌与作答、恢复存档、卡牌及赋能奖励、词汇准备完成后的剧情入口。

## 已修复

1. **出牌后有明显停顿**：手牌每次更新都重新生成 512×768 的卡牌图。改为按卡牌及可出牌状态缓存，共享缓存由游戏统一释放，切换回合不重复生成相同图片。
2. **准备完成后还需要绕回地图**：答题反馈页直接提供“词汇准备完成 · 进入剧情”，仍可选择继续远征。
3. **出牌与答题之间操作繁琐**：支持 Enter 结束回合。手牌获得键盘焦点时仍保留左右选牌、Enter 出牌，输入拼写时 Enter 提交。
4. **敌人伤害预告与结算难理解**：伤害预告注明“答对可闪避”或“答对伤害减半”；普通攻击因答对被闪避时，反馈明确说明原因。伤害规则保持现有实现。

## 性能对比

同一台机器，以当前玩家存档为起点、使用相同测试词库，满手 8 张牌、预热后连续 12 次更新的平均耗时：

| 操作 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 界面更新 | 274.8 ms | 74.4 ms |
| 存档与界面完整更新 | 306.9 ms | 92.3 ms |
| 单独存档 | 17.2 ms | 17.3 ms |

完整更新平均耗时减少约 70%。这些数字是当前机器上的同步处理时间，不代表所有设备上的帧率；首次遇到未缓存的卡牌仍需生成图片。

## 验证

- 生词本手动添加和重复词处理通过；4 个无例句自定义词可连续训练 20 回合，且不会错误生成语境填空题。
- 五组章节词汇各运行 20 个种子：共 100 局词汇准备、5220 次作答，包含答错和中途序列化后继续；均能完成掌握并结算奖励。
- 两种窗口尺寸：完成后的剧情入口、答题选项、拼写提交及反馈均可用。
- 1～8 张手牌在两种窗口尺寸下：居中、无横向滚动，每张牌可悬停与点击。
- 连续 48 次出牌/结束回合/作答/下一回合：战斗窗口及背景缓存持续复用，调整窗口尺寸无异常。
- 80 局普通远征、2387 次作答：卡牌、能量、弃牌、怪物机制和奖励回归通过。
- 四种题型、卡牌奖励和赋能选择布局通过；赋能选择能正确应用并回到地图。
- 朗读/收藏按钮重绘，以及攻击音效、动画结束和静止场景计时器检查通过。
