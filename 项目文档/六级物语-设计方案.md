## 1. 产品定位

一款将穿越冒险、女主互动与英语学习结合的 galgame 风格游戏。

玩家扮演拥有强大系统的男主，穿越多个世界，与不同女主合作解决危机。主线通过英文配音、字幕和听力理解题提供逐步提高难度的学习体验；背单词作为独立模块，获得的金币可用于商店购买主线道具和技能。

核心体验：剧情值得继续看，系统能力使用起来有爽感，学习成果能带来可见的游戏奖励。

### 1.1 已确定的设计原则

- 男主拥有非常强大的系统，可以穿越并帮助各个女主。
- 第一个世界采用赛博朋克风，第一位女主为陈星遥。
- 角色视觉参考用户提供的日系像素全身立绘，保留 galgame 的表情、对白与人物互动。
- 背单词是独立模块，可以自由进入，不按剧情章节组织或强制完成。
- 单词的具体含义不转换为技能。完成有效学习和复习可获得金币。
- 金币在系统商店消费，购买的道具、技能和升级可以在主线使用。
- 主线具有基础通关路线，不以刷金币、购买商品作为强制推进条件。
- 主线英语难度递增，后期以六级听力真题难度为目标。
- 每小节安排三到四道题，默认采用四道。

### 1.2 本稿保留为暂定的内容

作品副标题、男主姓名、其他世界及女主姓名、商品价格、金币数量、具体能力效果与最终结局均为设计提案，可以在制作中调整。

## 2. 三个模块与核心循环

```text
主线剧情：穿越世界 → 理解对话 → 回答问题 → 选择行动 → 推进关系与故事

单词训练：选取词汇 → 学习或复习 → 获得金币
                                  ↓
系统商店：购买道具 / 永久技能 / 技能升级
                                  ↓
主线使用：突破障碍 / 开启替代路线 / 发现支线 / 获得额外互动
```

### 2.1 主线剧情

负责冒险、悬念、女主关系与系统能力表现。英语学习主要体现在听懂剧情信息和回答听力题。

### 2.2 独立单词训练

玩家可在主菜单直接进入，自行选择学习时长和词汇范围。词库按照四级、六级、待复习、生词收藏等组织，不跟随主线章节解锁。

### 2.3 系统商店

将学习获得的金币转化为游戏中的装备与能力。商店商品可以设置主线阶段限制，以保护悬念和能力成长节奏；该限制由剧情进展决定，不要求完成指定单词章节。

## 3. 世界观与人物

### 3.1 男主

暂用姓名：陆川，玩家可以修改称呼。

原本是一名普通大学生，在意外中绑定「万象系统」，获得穿越世界的能力。性格机敏，有一点幽默感，遇到危险时愿意承担责任。

成长重点从帮助眼前的一个人，逐渐发展到理解不同世界的冲突，并掌握足以改变局势的力量。

### 3.2 万象系统

系统具有跨世界传送、目标解析、机械修复、空间操控等强大能力。基础能力随主线成长，商店提供额外能力、装备与升级，让玩家形成自己的行动风格。

系统能够展示未来可以获得的高阶能力，给玩家明确的成长期待。解锁之后可直接使用，按技能效果遵守冷却、范围或场景条件，不再触发临时背词任务。

背单词是玩家层面的独立玩法。剧情角色不需要讨论英文单词与超能力的关系。

### 3.3 女主设计原则

- 每个世界设置一位主要女主，有独立目标、专业能力、性格与困境。
- 女主提供男主缺少的世界知识、线索与判断，参与关键行动。
- 男主的强大能力能够突破常规障碍，女主仍有自己的选择权。
- 感情通过共同经历、信任和互相理解推进。
- 听力题答错不直接扣好感；关系变化由剧情行动决定。
- 各世界结束后保留返回机制，后续可扩展共同任务与日常互动。

## 4. 整体剧情结构

建议以四个世界单元和一个终卷构成长期主线。优先完成第一卷，再根据实际反馈扩展其他世界。

| 世界单元 | 主要女主 | 世界与核心问题 | 英语难度目标 |
| --- | --- | --- | --- |
| 第一卷：霓虹失名者 | 陈星遥 | 赛博朋克未来；妹妹失踪，居民身份被删除 | 四级基础逐步到四级较难 |
| 第二卷：白塔与禁咒 | 艾琳，暂定 | 奇幻大陆；治疗体系存在错误，研究者遭到追捕 | 四级较难到六级过渡 |
| 第三卷：第七日撤离 | 许知夏，暂定 | 灾后城市；救援、物资分配与隐瞒信息 | 六级过渡到六级目标 |
| 第四卷：记忆交易所 | 沈未央，暂定 | 记忆交易社会；证据冲突、记忆篡改与身份秘密 | 六级目标 |
| 终卷：系统的主人 | 前面各女主共同参与 | 调查系统来源，阻止强制统一世界的程序 | 六级综合理解 |

难度不只通过生僻词提高，还包括句式、语速、同义替换、信息密度、转折和隐含推断。最终难度需要配音与实际答题测试校准。

## 5. 第一卷：霓虹失名者

### 5.1 城市设定

未来都市「澜城」由天穹集团管理。数字身份决定居民的工作、交通、住房和医疗权限。一旦身份被注销，一个人便会逐渐失去正常生活的条件。

部分被注销者生活在地下，无法证明自己遭遇了什么，也无法通过正常渠道求助。

### 5.2 陈星遥

身份：地下电台记者，擅长网络调查与城市潜入。

性格：冷静、直接、有行动力，不轻易信任别人；习惯独自承担危险，熟悉之后会表现出克制的关心和幽默。

视觉方向：日系像素全身立绘，清晰方形像素、有限色阶、宽松机能外套、围巾与实用靴。银发蓝衣、黑发青蓝、紫发长风衣均已有概念稿，最终配色尚未确定。

识别元素：星形标识、录音设备、录音耳机。她保留离线录音，以防企业修改联网记录。

个人目标：寻找失踪的妹妹，公开居民被秘密注销身份的证据。

### 5.3 四章十二小节

| 章节 | 小节 | 主要剧情 | 能力与商品的使用机会 |
| --- | --- | --- | --- |
| 第一章：从天而降的陌生人 | 1.1 雨夜追踪 | 男主落入澜城，被识别为无记录个体；星遥带他躲避追捕 | 临时护盾、扫描器可提供额外选择 |
| 第一章 | 1.2 地下末班车 | 两人被封锁在废弃线路，寻找逃生路线 | 机械修复可快速启动运输车；基础路线为寻找备用能源 |
| 第一章 | 1.3 未来的录音 | 到达据点，妹妹留下的录音与现场信息发生矛盾 | 系统基础解析发现录音异常，建立第一条悬念 |
| 第二章：不存在的人 | 2.1 地下居民 | 了解失去身份的人如何生活，帮助一名需要就医的孩子 | 医疗喷雾改善救助结果；无商品时完成正常求援 |
| 第二章 | 2.2 被再次删除 | 临时恢复的权限再次消失，发现自动注销机制 | 电子入侵可获得额外日志；基础路线为调查实体终端 |
| 第二章 | 2.3 核心运行人员 | 找到“城市优化”计划，妹妹被标为研究所人员 | 无人机、线索扫描器解锁补充情报 |
| 第三章：她留下的声音 | 3.1 三重门禁 | 研究所要求身份、生物验证与实体钥匙 | 入侵、隐身、传送提供不同潜入路线 |
| 第三章 | 3.2 预测牢笼 | 妹妹被用于训练城市预测系统；她的声音藏在模拟结果中 | 能力提升行动效率，调查选择决定线索完整度 |
| 第三章 | 3.3 不可预测的来客 | 星遥坦白自责，男主表明身份；系统无法预测异世界来客 | 两人共同制定救援计划，关系进入信任阶段 |
| 第四章：让城市听见 | 4.1 清除倒计时 | 集团准备清除地下居民区，救援与公开证据必须同时进行 | 护盾、无人机、空间技能改善救援路线 |
| 第四章 | 4.2 全城广播 | 星遥救妹妹并播出证据，男主突破企业封锁 | 基础主线能力保障高潮；商店升级提供更强表现与支线收益 |
| 第四章 | 4.3 重获姓名 | 身份归还，城市开始重建；男主获得返回澜城的世界锚点 | 根据行动展示救援结果、关系对白与额外情报 |

每小节默认四题，第一卷共四十八道听力理解题。题目具体位置和音频长度在剧本阶段确定。

### 5.4 第一卷结束

男主与星遥救出妹妹、公开证据，打破集团对身份记录的秘密控制。城市仍需重建，星遥选择留下继续调查。

她把星形徽章交给男主，作为可以再次返回澜城的世界锚点。

建议将“成功解决主要危机”作为基础结局，再根据玩家行动区分情报完整度、救援表现与两人的关系收束。避免把学习题答错变成不可逆的悲剧结局。

## 6. 主线播放与听力题

### 6.1 小节长度

以六级长对话为主要体量参照，每小节目标约 280–320 个英文词；开场旁白、题干和答题反馈单独计算，避免挤占正文。

官方参考：[全国大学英语四、六级考试大纲（2016 年修订版）](https://www.neea.edu.cn/res/Home/1704/55b02330ac17274664f06d9d3db8249d.pdf)。其中六级长对话每篇约 280–320 词、每篇四题，语速约每分钟 140–160 词。

早期使用更清晰、更慢的配音，后期逐步接近目标语速。原创对白保持自然，不为塞入词汇而牺牲角色表达。

### 6.2 剧情模式

- 每小节分成四个叙事段，每段结束出现一道题。
- 每段目标约 70–80 个英文词，通常包含数句对白，允许按情节自然调整。
- 本句配音结束后，点击背景、立绘、中文或对话空白，进入下一句并立即播放。
- 英文单词点击保留查词；控制栏操作与背景推进分开处理。
- 选择题仅考查已经播放的信息，不泄露后续剧情。
- 提交只记录选项，整节结束后统一显示正确答案与解析。题目重听返回对应剧情开头，仅开放英文；节末整节重听才可开放中文。
- 听力理解题与剧情行动选择使用不同提示，避免玩家把标准答案误认为角色立场选择。

### 6.3 连续听力模式

作为后续可选功能，完整播放一个小节后集中回答四题，提供更接近考试的训练体验。期间不作依赖理解答案的分支推进；剧情行动安排在答题之后或小节边界。

### 6.4 题型递进

| 阶段 | 主要训练 |
| --- | --- |
| 初期 | 人物、地点、时间、具体行动、直接原因 |
| 中期 | 同义替换、转折、建议、因果关系 |
| 后期 | 隐含态度、条件限制、多方立场、综合推断 |

原创剧情配原创题，明确标注原创内容。真题模式单独标记来源、年份、材料类型与改写情况，不把合成配音或原创台词称为考试原文、原音。

## 7. 独立背单词模块

### 7.1 入口与词库

主菜单提供「单词训练」入口；剧情安全暂停后也可通过菜单进入。

词汇入口包括：四级词汇、六级词汇、生词收藏、到期待复习。按词汇与个人掌握程度组织，可设置本次学习数量或自由结束，不采用剧情章节式任务。

词条提供英文、音标、发音、中文释义与例句。剧情中收藏的词进入同一生词本，不要求玩家学完才能返回剧情。

### 7.2 小游戏形式

首期优先实现：英文选义、听音选词、先回忆再翻卡。

后续可扩展：拼写填空、易混词辨析、例句选词。不同题型共享掌握记录，不各自重复发放首次奖励。

### 7.3 训练流程

```text
选择词汇范围 → 学习或回忆 → 作答 → 反馈与巩固
                                       ↓
                          更新掌握状态与复习日期
                                       ↓
                           显示本次实际获得金币
```

用户可自由结束，已完成部分立即保存。答错不扣金币，进入巩固队列。

既有 1、3、7、14、30 天复习间隔可作为基础沿用；忘记后重新安排巩固。具体掌握阈值后续测试确定。

### 7.4 金币奖励原则

- 首次有效掌握和到期成功复习提供金币。
- 同一个词在同一奖励周期内不因重复切换题型而重复奖励。
- 当天短时间重试主要提供巩固反馈，避免反复答同一题成为最划算的刷钱方式。
- 自评翻卡可用于复习，但金币奖励应结合客观辨义或听音确认。
- 不扣错题金币，不使用强迫连续签到或中断学习惩罚。
- 奖励记录与金币变更一并保存，重启不能重复领取。

首期数值提案：新词有效掌握 +5 金币，到期复习成功 +2 金币。此数值仅用于原型调试，需根据学习时长与商品获得速度调整。

## 8. 商店、道具与技能

### 8.1 商品类型

| 类型 | 示例 | 主线用途 |
| --- | --- | --- |
| 消耗道具 | 医疗喷雾、临时护盾、隐身装置、应急能源 | 救助、抵挡危险、潜入、临时供能 |
| 永久技能 | 机械修复、电子入侵、短距传送、时间减速 | 提供可反复使用的突破方式 |
| 技能升级 | 范围扩大、持续时间延长、冷却减少 | 强化已拥有能力 |
| 辅助装备 | 线索扫描器、便携无人机 | 发现补充线索、开启支线、改善侦察 |

技能名称与效果为暂定。首期应挑选少量用途明确的商品，不提前制作大量缺乏使用场景的技能。

### 8.2 首期价格提案

| 商品 | 建议价格 | 获得类型 |
| --- | --- | --- |
| 医疗喷雾 | 20 金币 | 单次消耗 |
| 临时护盾 | 30 金币 | 单次消耗 |
| 隐身装置 | 40 金币 | 单次消耗 |
| 线索扫描器 | 100 金币 | 永久装备 |
| 机械修复 | 150 金币 | 永久技能 |
| 电子入侵 | 200 金币 | 永久技能 |

目标体验：一轮约 20 个新词训练可获得一件辅助装备，或若干消耗道具；永久技能需要数次训练积累。价格必须随真实学习体验调整，不用增加重复刷词要求来延长游戏。

### 8.3 购买与使用

- 商店显示金币余额、效果、适用场景、是否消耗、是否已拥有及开放条件。
- 金币不足不扣款，永久商品不重复购买。
- 消耗道具可以叠加，永久技能与升级分别记录。
- 主线到达可用场景时显示商品对应行动选项，也可查看背包。
- 选择预览不消耗道具，确认并执行行动时才扣除。
- 每次行动绑定当前剧情状态，连续点击不重复扣除或发放结果。
- 技能使用效果体现为明确的画面、配音、对白或路线变化。

### 8.4 避免卡关

所有关键障碍提供基础路线。例如没有电子入侵时，可以与星遥寻找备用钥匙；拥有技能时可直接绕过门禁，获得不同对白或额外线索。

必要的高潮能力由主线提供基础版本，商店升级增强效果。基础结局不要求购买全部技能，也不根据玩家花费金币多少评判女主关系。

## 9. 画面与声音

### 9.1 美术方向

角色采用用户确认的日系像素立绘方向：全身构图、清晰颗粒、有限色阶、可读的表情与服装轮廓。第一卷背景采用赛博朋克城市、雨夜街巷、地下电台和研究所等场景。

优先统一人物与背景的像素密度、光照和配色。角色概念稿后续需要转为一致规格的实际素材，并检查透明边缘。

缩放像素素材使用最近邻方式，避免双线性模糊；布局仍适应窗口尺寸。优先保持素材纵横比，必要时使用留边或受控裁切。

### 9.2 表情与对白

陈星遥首期表情：平静、警惕、轻笑、担忧、愤怒、放松。先完成少量高频表情，再扩展动作。

保留透明对话区、中英文独立显示、逐句播放、全文播放、对话记录和英文单词查词。

### 9.3 配音

角色声线保持一致，男女主与旁白区分。学习阶段调整语速与信息密度，后期配音逐步接近六级听力目标。

暂停从原位置恢复；页面切换和打开题目时妥善停止或暂停音频。题目重听可以定位到对应片段。

## 11. 存档与旧版兼容

继续使用当前目录的 `save.json`，升级时保留已有生词、学习进度、设置和剧情记录，不自动重置旧数据。

新增数据建议包括：

- 金币余额与奖励领取记录。
- 道具数量、已购装备、已解锁技能与技能等级。
- 单词学习状态、复习日期、金币奖励去重信息。
- 各世界、小节、剧情行动与听力题进度。
- 女主关系状态、世界锚点与结局记录。
- 存档格式版本号。

旧存档缺少新字段时，补齐安全默认值。旧版经验等级先保留，不直接换算为金币，避免凭空改变经济系统。

保存继续采用临时文件与替换方式，保证购买、领取与道具使用的数据一致。迁移前建立可恢复备份。

## 12. 开发路线

### 阶段一：独立学习与经济原型

完成自由单词训练、有效掌握判定、金币奖励与去重、商店购买、背包与技能记录，以及旧存档兼容。

验收重点：学习可以自由结束；金币显示清晰；重启不重复领奖；重复购买和余额不足处理正确；旧生词与进度保留。

### 阶段二：第一卷试玩

优先制作第一章三个小节、陈星遥像素立绘及基础表情、对应配音与十二道理解题。安排至少一个障碍，展示“基础路线”和“使用商店商品的路线”。

验收重点：无金币仍可通关；商品有明显用途；题目只考已播放内容；点击推进即播放下一句；窗口缩放和全屏显示正确。

### 阶段三：完成第一卷

完成四章十二小节、四十八题、救援高潮、妹妹支线和世界锚点。依据试玩反馈调整学习收益、商品价格与英语难度。

### 阶段四：扩展其他世界

复用已经稳定的剧情、训练、商店与存档机制，逐步制作奇幻、灾后城市与记忆交易世界。后期补充连续听力训练、更多题型与终卷。
