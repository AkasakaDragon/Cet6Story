# 酒馆经营动作

使用内置 image_gen.imagegen 生成；传入既有角色原图和 reference-2.png 作为参考。完整提示词见 generation.json。素材保留透明 Alpha，运行时按透明轮廓的实际行列边界读取，不修改生成原图。

每张四列，动作按行排列：

- aelia-actions.png（六行）：点单／结账、托盘、擦桌、收碟、备饮、整理杯碟。选用同朝向的前两帧，0→1→1→0 循环，避免生成图后两列转身造成动作跳变。
- guest-actions.png（四行）：坐姿等待、吃饭、饮用、付款。
- lyse-actions.png（六行）：取料、切配、烹饪、装盘、清洗、补柴。
- luchuan-actions.png（两行）：站立待命、看账本与指导。
- rest-actions.png（两行）：艾莉娅、莉瑟放松休息。
- delivery-walk.png（四行）：背面单盘、背面双盘、正面单盘、正面双盘；右方向水平镜像。

动作按营业状态实际调用；送餐寻路时使用拿托盘走路，抵达服务位置后显示对应动作。收桌先擦拭再收碟。客户结账后离开，员工继续清理。双盘配送分别访问两张桌子的服务位置。

source/TavernHallActions.cs 负责状态映射及精灵表绘制，source/TavernHallNavigation.cs 负责四方向地面寻路，桌椅含避让边距。客人座位不作为行走终点，行走止于桌边通道再切换坐姿。

## 顾客坐姿与用餐（2026-10-13）

guest-dining-ne.png 为新增的右上朝向动作图：三行分别为坐姿等待、伸勺／举勺／入口／放下、举杯／抬杯／饮用／放下。保留既有镇民的头发、胡须、米色衬衫、深绿背心及棕色裤靴；图片生成传入既有顾客图与 reference-2.png 原图，没有使用开罗人物素材。结账期间仍然坐着等待，离店才切回行走。

source/TavernHallDining.cs 按透明背景中的四个独立轮廓读取每行，避免生成图的列间距不齐造成裁掉碗和手。运行时以坐垫上的臀部锚点对齐坐姿，独立于行走脚底。source/TavernHallDepth.cs 的座位配置同时保存坐垫位置和桌面方向；现有四个服务座位均位于桌子的左下侧，朝右上方，左侧方向可用水平镜像。当前图不包含另外两种正面方向；增加其他侧座位时需补对应方向的动作。

场景原画已经包含桌椅，因此通过原画的局部窗口实现分层：底图桌椅→人物→桌沿遮挡→桌沿上方的手、碗与上半身→椅背木条及立柱。原画与全景相机共用同一坐标转换，不另画或移动桌椅。用餐节奏按顾客自己的 progress 驱动，暂停时停在当前姿势，营业速度变化时同步；顾客 id 的少量偏移避免全桌同时举勺。
