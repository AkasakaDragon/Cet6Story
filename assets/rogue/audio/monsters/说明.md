怪物专属音效均为原创程序合成，不使用外部采样。格式为 44.1 kHz、双声道、16 位 PCM WAV。

每种怪物有四个独立音效：normal（普通攻击）、hurt（受击）、skill-a（技能 A）、skill-b（技能 B）。

| 文件前缀 | 怪物 | 声音特征 |
| --- | --- | --- |
| wood | 苔藓木灵 | 木质敲击、枝叶摩擦、低频藤蔓 |
| spore | 荆棘孢子兽 | 颗粒播种、连续爆裂、尖刺 |
| stone | 石像哨兵 | 碎石撞击、低频重锤、符文共振 |
| echo | 回响灯灵 | 空灵钟鸣、谐波回响、灵火 |
| ember | 余烬蜥蜴 | 火焰呼啸、燃烧噪声、撕咬 |
| armor | 熔甲幼兽 | 金属甲片、熔甲震荡、爪击 |
| ancient-tree | 古树守卫 | 更低沉的树木共振 |
| sealed-knight | 封印骑士 | 沉重石甲、符文重击 |
| lava-troll | 熔岩巨魔 | 厚重熔甲、低频震荡 |
| gatekeeper | 古界守门者 | 低频咆哮、古老谐波、符文脉冲 |

源代码：source/MonsterAudio.cs。重新生成：powershell -ExecutionPolicy Bypass -File tools/create-monster-audio.ps1。

技能 A/B 对应现有招式循环，不改变伤害或规则。石像技能 B 是第二回合重击，第三回合冷却不播放攻击；余烬蜥蜴第四回合散热不攻击。被击败、重击被打断、熔甲震荡取消时不播放敌方攻击或技能。闪避及护盾抵挡仍有敌方出招表现。
