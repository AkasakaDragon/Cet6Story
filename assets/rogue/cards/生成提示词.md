# 原创卡牌与支援素材生成记录

生成方式：内置 image_gen，未使用 API CLI。

- illustrations.png：一张严格 4×4 的原创卡牌插画图集；成人黑发男主、白发黑衣紫衬衫女主，幻想与科技交融、厚涂卡牌插画。按阅读顺序分别是指引、屏障、标记、默契、凝神、净化、破甲、掩护、蓄势、穿透、共鸣、战术重整、心意相通、双星协奏、逆转、终幕。无文字、无卡框，文字和品质框由程序绘制。
- support-sprites.png：一张严格 4×2 的像素精灵图集；上排为黑发黑衣青色饰边男主的待机、单手施法、双手屏障、受击准备四种姿态，全部面向右；下排为面向左的孢子兽、回响灯灵、熔甲幼兽、木灵。全身、独立等格、不重叠。追加背景去除指令，保留所有角色和位置，移除黑灰底及弥散光晕，输出真正透明 alpha PNG。

完整素材已存入游戏 assets/rogue/cards，游戏运行与打包无需访问外部服务。

## 第二版界面素材

- ornate-frames.png：内置 image_gen 生成一张 3×1 卡牌边框图集。三张严格同布局的竖版雕刻卡身：木纹铜饰绿宝石、银蓝金属蓝宝石、暗金紫晶；拱形轮廓、椭圆空插画窗、空白卷轴名称与羊皮纸规则栏、左上蓝色费用宝石。无文字无数字，透明外背景。游戏程序填入原创插画与中文规则。
- quiet-scenes.png：内置 image_gen 生成一张三行横向场景图集。上为雾林遗迹，中为地下石殿，下为暗色火山峡谷。低饱和、低对比，大块轮廓，左右外缘保留环境特征，中部留白；没有角色、灯笼、花朵、火花或文字，以角色和怪物可读性为优先。
