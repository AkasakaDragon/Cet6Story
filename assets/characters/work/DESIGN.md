# 酒馆工作服设定

用户最新决定采用彩色工作服版本，并加强细腻像素绘画效果。此决定替代此前统一黑色的要求。

- 陆川（厨房）：米白卷袖亚麻衬衫、深蓝短马甲、星形扣、亚麻厨房围裙、深色长裤、棕靴，配木勺和擦手布。
- 艾莉娅（传菜）：束起红发，保留白花；米白衬衫、酒红工作裙、棕色马甲、半围裙、结实短靴。卸下铠甲与武器，配传菜托盘。
- 莉瑟（吧台记账）：银白发整理并束至肩后，保留紫花缎带；紫色上身、浅紫灰长裙、收紧袖口、半围裙、紫色挂坠，配账本与羽毛笔。

画风遵循 assets/art-style/STYLE.md 与 reference-2.png：清晰方形像素簇、阶梯轮廓、节制局部色阶，保持精细的角色与服装细节，不改成粗颗粒卡通。
